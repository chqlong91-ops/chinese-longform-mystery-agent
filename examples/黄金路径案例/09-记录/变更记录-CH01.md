# CH01 归还时间窗变更

## 请求

把物品归还从“三个月内每周一件”改为“清柜通知后一周内集中归还”，其他核心因果尽量不动。

## 保留约束

- 四年前物品由不同旧同学分别代管；
- 周岚曾暂用并补齐互助款；
- 方宁只同意有限保密；
- 高成扩大含混说明；
- 结局先取得方宁对公开范围的意见；
- 不新增系统后台、监控或定位能力。

## 新旧事实

- 旧：三个月内，每周一件，形成缓慢重复谜面。
- 新：清柜通知后一周内，八件物品由不同登记人集中归还。

## 影响

| 产物 | 影响 |
|---|---|
| 项目种子与配置 | 谜面时间描述必须更新 |
| 时间线 T08、T09 | 周岚联络和林澄发现节奏改变 |
| 线索 C01 | 从“规律性每周”变为“同周密集、登记时间分散” |
| 嫌疑路径 | 周岚组织性更容易被怀疑，需要保留其他人的自主决定 |
| 揭示阶梯 | 冒名解释较弱，共同行动解释提前增强 |
| 章节地图 1-4 | 调查压缩，必须用登记顺序和物品使用痕迹维持阶段变化 |
| 恢复包与状态 | 最近变化、当前状态和下一步更新 |

## 状态撤销

- 保留：四年前核心因果的 `creative-confirmed`（夹具）和相关时间线。
- 暂时撤销：当前谜面、线索 C01、前四章的 `design-plausible`。
- 不受影响：现实研究项、C03/C06/C07/C08、事实与人的结局。

## 新现实主张

无。集中归还是人物行动，不依赖新系统能力。
