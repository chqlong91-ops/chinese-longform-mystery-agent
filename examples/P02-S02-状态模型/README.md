这里的对象只用于验证状态模型，不是小说创意确认，也不包含可进入正文的案件事实。

| 夹具 | 场景 | 主要验证 |
|---|---|---|
| F01 | 新建章节待规划 | 初始状态、P01 结构引用、无正文 manuscript=no |

| F03 | 正文已确认但待审计 | 派生标签和独立状态 |
