# P02-S05 Evidence-Ready 门禁夹具

本目录只验证 S05 的对象、研究、门禁、失效与恢复协议。全部内容均为合成元数据，不代表任何真实小说事实、真实用户创意确认、现实专业建议、稿件或生产门禁。

- F01：全部决定性主张通过，局部 ERE yes。
- F02：同章两个消费者一个通过、一个缺失，聚合 partial。
- F03：所需能力被适用来源否定且无退路，ERE no。
- F04：声明范围确无决定性现实依赖，有 NAD 的 n/a。
- F05：能力存在但故事人物无访问/使用权。
- F06：真实字段窄于所需命题，禁止过度结论。
- F07：来源过期且法域不符，不能支持当前主张。
- F08：同适用域权威来源冲突，evaluation conflict。
- F09：退路已核验且测试输入明确采用，退路分支 yes。
- F10：来源撤回只使关系可达 ERE stale，并可最小恢复。
- F11：危险来源只形成 safe-summary，不保存操作细节。

每个夹具明确对象/版本、来源/消费者指纹、预期 value/evaluation、停止状态、允许工作、S06 资格、禁止推断和唯一下一步。fixture 中的 confirmed 只表示测试前置，不继承为真实项目确认。
