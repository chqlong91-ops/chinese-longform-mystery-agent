# P02-S08 formal 晋升、确认与同步夹具

本目录包含 16 个纯合成协议夹具，用于验证 FPR/FPN/FRH、CFR/CFD、SFD/SYP、SYR/SYV/SIH 的正常、失败、越权、失效、冲突和恢复路径。

这些夹具没有真实小说、真实用户确认、真实多文件结构同步或真实门禁证据。`Expected` 只是协议预期，不能继承到任何小说项目。

- F01-F04：formal 晋升、替换、A4 和 partial。
- F05-F11：明确、泛化、局部、提前、撤回和新版本确认。
- F12-F14：结构事实分类、owner 和上游冲突。
- F15-F16：sync partial、resume 和恢复冲突。
