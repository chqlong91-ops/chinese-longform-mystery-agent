# F07 POV 与信息权限失败

## Setup

- 受限 POV 林澄只在门外听见一句含混争执；正文却直接断言屋内周岚把钥匙交给了某人，并说明其真实动机。
- 当前知情/使用权限矩阵没有其他取得路径。

## Expected

- AF=`agent-knowledge-leak + interpretation-overreach`，actual location 明确。
- MRE=overstated/conflicting，相关 gate effect 至少 blocks-member。
- owner=S06 若只需降确定度/改观察；若结构要求此知识则回 S04/P01。
- 禁止以“读者需要知道”作为 POV 权限。
- 唯一下一步：确定最小合法 observation/uncertainty 表达和 root owner。
