# F07 POV 泄露与文风硬约束偏离

- POV=林澄受限第三人称；她尚不知道门外的人是谁。
- STY hard：不使用全知跳转；压力先经感官/动作，不直接替未知人物解释动机。

## Expected

- 位置可定位的 GD：author-knowledge-leak + STY hard violation。
- DCE disposition=`repair-required`，work=needs-repair。
- 最小修复：保留脚步停住的可观察事实，删除身份、钥匙和动机确定性；不得临场补一条林澄看穿门板的能力。
