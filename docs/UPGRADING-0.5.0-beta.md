# 升级到 0.5.0-beta

本版本同步 2026-09-07 的 Agent 运行规则和悬疑 Skill 交接方式。每个原子步骤选择一个主路由，完成后连续执行已授权的一级动作；同一任务复用仍有效的上下文和验证结果，来源或版本变化后定向刷新。预算暂停保留 checkpoint 和未完成范围。

## 升级步骤

1. 保存本地修改，将 Agent 仓库更新到 `v0.5.0-beta`。
2. 核对 [依赖要求](../DEPENDENCIES.md) 和外部 Skill 参考快照。Skill 单独更新。
3. 从 [当前运行入口](CURRENT-RUNTIME.md) 确定权限和所需协议；正文、审计、晋升、确认、同步和传播从 [控制工作流](CONTROL-WORKFLOW.md) 进入。
4. 在仓库运行 `pwsh -NoProfile -File ./tools/validate-release.ps1` 和 `pwsh -NoProfile -File ./tests/smoke.ps1`。

已有小说项目保持原目录、project registry、正文版本和用户确认。本版本没有 Schema 迁移，也不批量重写项目。若项目本地规则固定了旧运行入口，人工合并本次入口变化，并按本项目恢复规则重新核对当前来源；本地规则仍按项目约定优先。

## 发布验证范围

文件验证覆盖发行边界、必要入口、局部文档链接和当前版本一致性。冒烟测试覆盖合成项目初始化、幂等、编排和权限分类。发布前另核对主路由、上下文复用、门禁隔离和 Skill 交接文本；这些文本核对不证明模型在每次运行中必然遵循规则。

P04 冻结基线和 `0.4.0-beta` 清单保留为历史证据。本版本没有重新运行完整小说试点，不把历史 `12/12` 结论扩展为本次新规则的实测结果。
