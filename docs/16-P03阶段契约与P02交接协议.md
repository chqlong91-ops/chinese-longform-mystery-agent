## 目标

P03 在 P01 案件设计和 P02 逐章生产基线之上，建立可长期协作、可验证、可恢复的全书生产、长程一致性、唯一装配、整书终审、全书确认、冻结交付与恢复闭环，使一部真实中长篇中文悬疑小说能在文件状态与实际正文一致的前提下完成。

## 阶段 required

`P03-R01`—`P03-R12` 分别要求：冻结交接；全书对象与状态；生产编排；长程上下文与一致性；分批逐章生产；分幕/跨幕审计；唯一 ASM；整书终审与修复；独立终态；真实完整试点；安全原创与事实诚实；可追踪可恢复。任何后续 S 任务不得删除 required、扩大出版/专业保证/并发/无人值守范围，或重做 P01/P02 owner 内容。

## P01/P02/P03 交接

- P01 继续拥有案件真相、真实时间线、知情/权限、线索、嫌疑、揭示、现实依赖、双重结局和 design-plausible。
- P02 继续拥有章节对象、稿件层、CC/SC/BT/IS、ERE、正文候选、章节审计/MR、formal 晋升、CFD、SYV、章节变化、单 boundary 和章节恢复。
- P03 只拥有全书对象、生产批次、长程图、全量 boundary 聚合、ASM、FAR/FAF/FRP/FAV、全书确认、release、recovery 和八类全书状态。
- P03 finding 必须回唯一 owner；不得原地覆盖案件 truth 或章节 formal。

上游协议语义按 `reuse-as-protocol` 复用；P02 实际三章、变化、单 BAV、L5 决定和 L6 恢复按原 scope `reuse-as-evidence`；全部章节、全部分幕、长程、ASM、整书审计、全书变化、确认、release 和恢复必须 `revalidate-at-book-scope`；汇总、LONG-01、fixtures 和 legacy 仅 `reference-only`。`PI-01`—`PI-12` 所列错误继承全部禁止。

## 完整规模与阶段验收

完整试点原则上不少于 12 个章节或等价结构单元，并覆盖至少三个分幕或用户 L5 确认的等价结构；必须有 current brief、完整章节/分幕 manifest 和双重结局范围。三章、样章、合成片段和 legacy 合并稿不能替代。试点只在 S10 选择，S01 不预选任何小说。

P03 只有 `P03-AC01`—`P03-AC11` 全部 satisfied 才能阶段完成：十个 S 任务闭合；真实完整规模；逐章 current 证据；全部分幕/长程；唯一 ASM；完整终审；全书关键变化；四个独立终态；36 个书级场景和 16 个强制失败；全量回归/L6 恢复；诚实阶段报告。

## 证据与追踪

沿用 L1 protocol、L2 synthetic、L3 isolated-file、L4 real-project、L5 real-user、L6 clean-session。L4 以 `L4-C` chapter、`L4-A` act/boundary、`L4-B` book-structural、`L4-M` full-manuscript 限定 scope，profile 不互相升级。

状态证据链固定为：`requirement/AC -> object/version/scope -> required evidence -> actual/post-read -> atomic event -> independent state -> acceptance`。索引、计划、文件存在、写入事件、exit 0、hash、mtime、summary 或多个低等级结果不能单独授语义状态。book confirmation 只接受 L5；clean-session 只接受 L6。

## 八类独立状态

`chapter-production-complete`、`act-boundaries-verified`、`long-range-consistent`、`book-assembled`、`final-audited`、`book-confirmed`、`release-verified`、`recovery-verified` 各有独立 object/version/scope、value/evaluation、owner、evidence、失效和 next，互不蕴含。

`final-audited` 只由唯一完整 current ASM 上的 L4-M FAR、FAF closure 和 current FAV 授予。minimum audit 必须覆盖因果、时间/路线、线索六项、公平反事实、POV/权限、物件/凭证/数量/证据命题、嫌疑终态、现实能力、全书连续性/人物/节奏/文风、事实/法律/情感/道德闭合、原创和安全。blocking/major FAF、决定性 research 或 ASM drift 未解决时不得 yes。它不等于用户确认、release、recovery、出版准备或专业保证。

## Controller、授权与读取

P03 controller 只做路由、批次、聚合、装配/终审编排、独立状态写回、停止和恢复；专业结论归 `craft-social-mystery`、`novel-writing`、`novel-project-strategy` 及 P01/P02/P03 owner，重大方向/范围/确认/release/clean-session 授权归 User。

A0-A5 不互相包含。日常使用最小上下文和定向扩展；完整 manuscript 读取仅限声明的 ASM 装配验证、FAR 和明确 required 的全书重审，并必须绑定唯一 ASM、scope、目的、Skill/owner、required/not-read、允许输出、禁止写入和 checkpoint。permit 不继承到后续 run。

## 停止、失效与恢复

`STP-01`—`STP-17` 覆盖 source drift、双 current、scope mismatch、错误继承、规模不足、章节门禁、分幕/长程、ASM、full-read 越界、终审、确认、release、recovery、owner、协议冲突、安全和 no-progress。

内容、结构、truth/现实能力、协议、记录和用户决定变化分别按可达 scope/dimension 失效；新 chapter/ASM/BK version 不继承旧 CFD/FAV/BCD/BRV/BRTV。恢复动作每次只选 resume、replan、rebuild、repeat-audit、route-owner、request-user/A4、abandon 中一个。相同 root cause 两轮无改善即 no-progress。

恢复包依赖文件而非旧聊天；每次 source/status/next 变化创建新 version，旧包 historical。P01/P02 frozen 冲突只创建 finding 并回对应 owner，不在 P03 静默修复。
