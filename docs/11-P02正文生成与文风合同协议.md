- 对应任务：P02-S06

## 目标与边界

本协议把 current CC/SC/BT/IS、PCE/WH、ERE、L0-L4 和项目文风合同转换为一个明确获准、可追溯、可局部修订并可跨会话恢复的 exploration/raw/revised 正文候选。

S06 只建设候选生产能力。它不重写 P01 案件结构，不运行真实外部研究，不直接创建/覆盖 formal，不执行用户确认或结构同步，不判定 `manuscript-realized`，不执行 S07-S10，也不授予 `final-audited`。

## 七类事实分权

| 事实 | 规范证据 | 不代表 |
|---|---|---|
| 可请求写作 | current PCE/WH 与 eligible scope | A3、正文存在 |
| A3 已授权 | current WA 绑定 DR/版本/范围 | drafted、formal、确认 |
| 候选已生成 | current MS version、位置、指纹、PGR | 可审、门禁 |
| 可交 draft-review | DCE reviewable + PRH | formal/S07 已通过 |
| formal 已晋升 | S08/A4 formal-promoted 事件 | confirmed/synced/manuscript |
| 正文已实现 | S07 对 current formal 位置的专业评价 | final-audited |
| 用户已确认 | 明确对象/版本/范围的确认记录 | formal/sync/现实正确 |

任一事实不能从相邻事实自动推断。

## 写作模式与稿件结果

| Mode | 授权 | 合法来源 | 目标 | 状态边界 |
|---|---|---|---|---|
| `draft-new` | A3 | current 结构/WH/ERE/context/STY | raw new MS | 不自动 formal/confirmed |

## DR 与 A3

DR 至少声明：current CH/CC/SC/BT/IS、mode、source/target MS、target layer、write scope、start anchor、end condition、guardrail、allowed/preserved/prohibited、PCE/WH/ERE/CV/STY 指纹、验证、stop 和唯一下一步。

WA 至少声明：authority level、authorization basis、authorizer/evidence、精确 DR/目标/层/范围/动作、保留/禁用、有效期、撤销触发和不包含事项。

A3 合法至少要求：

1. DR/CH/MS/层/范围唯一；
2. 授权证据明确指向 current DR；
3. 核心创作方向可消费；
4. PCE/WH、ERE、CV、STY 和 WA 的共同 eligible scope 与 write scope 相同；
5. start/end/max scope 可判断；
6. 无 blocking conflict；
7. 来源指纹 current。

“继续”只有在上一轮完整披露唯一 DR、目标 MS、下一 SC/BT、终点且所有指纹未变时，才可形成 `continuation-of-disclosed-action`；否则 `pending-confirmation`。

## 文风合同

STY 作用域按 project -> act/arc -> chapter -> scene/POV/slice 继承和局部覆盖。同一 scope 只允许一个 active STY；覆盖必须声明 inherits/overrides/preserves/expiry。

来源优先级：项目本地硬规则 -> 用户明确决定 -> 项目自有已确认文本 -> 用户自有合法样本 -> 高层抽象特征 -> provisional。formal 层本身不等于已确认。

约束类别：

- `hard-constraint`；
- `preserve-by-default`；
- `preference`；
- `allowed-variation`；
- `prohibited`；
- `open`。

可观察字段覆盖叙述语法、句法/段落节奏、词汇/register、对话/心理/观察、感官/修辞、说明/证据、称谓/格式和禁止/开放项。

对话、内心、游离思绪、具体观察、身体感、暧昧和节奏重复默认是风格承载材料。删除前必须证明它不承担 character、voice、information、pacing、tension、atmosphere 任一功能；优先局部手术，不把具体质地压成摘要。

“冷峻、克制、细腻、电影感、高级”等必须转换为“目标功能 -> 可观察行为 -> 位置 -> 禁止极值 -> 允许变化 -> 证据”。统计只能定位异常，不能独立裁决。

命名作者/作品只抽象高层功能，排除个人句法、措辞、声音、标志性对象/职业/关系/机制/揭示顺序；需要 P01/结构证据证明至少三个结构维度实质不同，否则回上游或拒绝模仿部分。

## 正文上下文与起笔

S06 复用 CR/CL/CV，`task_profile=drafting`。required claims 至少覆盖 target、start-state、intended-delta、permission、reality、style、continuity、output 八组。

L0 是 DR/WA/MS/start/end；L1 是项目/POV/ERE/STY/A3 硬约束；L2 是目标及必要近场全文；L3 是远场结构切片；L4 默认排除未来正文、旧草稿、旧聊天和无关文本。

四种模式分别使用：

- draft-new：必要上章结尾/本章前文 + current 场景结构；
- continue-current：source MS 稳定末端、未完成 BT 和语言/动作断点；
- rewrite-local：目标全文、足够前后文、保留材料和触及主张；
- explore-isolated：实验所需最小事实/样本，保持隔离。

连续性锚点至少记录 time、location、POV、cast、body/emotion、object/access、knowledge、language、scene/BT 和 source fingerprint。

稳定位置使用 `<MS-ref>#<scene/section>/<paragraph/beat>@<excerpt-fingerprint>`。行号只辅助；指纹不符时不得自动偏移猜测。

CV sufficient/context-ready 至少要求 L0 唯一、blocking L1-L3 当前且实际读取、八组主张覆盖、输出许可足够、L4 排除可见、无 stale/conflict、验证和唯一下一步明确。context-ready 不授予 A3 或门禁。

定向扩展一次只追一个 blocking claim，默认最多三轮；同一缺口连续两轮无新增覆盖为 no-progress，不转向全稿扫描。

## 场景/节拍到正文

生成前按恢复唯一性、授权、结构、现实、上下文、文风、状态和输出顺序检查。

默认最小单元是一个 BT 或同一 SC 内不可分割 BT 组。即使授权整章，也按 SC/BT 串行 checkpoint。每行 expected realization 记录 source、narrative job、visible form、state before、required delta、allowed assertion/qualifier、forbidden、style duty 和 expected location。

生成顺序：

1. 建立 entry 与必要转场锚点；
2. 让人物带着目标、阻碍和代价进入；
3. 把 input/action-or-pressure/delta/next-cause 写成现场经验；
4. 按 IS 窗口执行 appear/reinforce/reinterpret/payoff/withhold；
5. 按 ERE 最大命题、qualifier、权限和 safe-output 表达；
6. 形成至少一种信息/压力/关系/危险/决定/主题变化；
7. 写入新 MS version，记录位置、指纹、PGR 和 checkpoint。

核心人物首次有效登场必须有身份/角色、为何在场、与当前事件/POV 关系、第一印象，并至少一个外部特征和一个行为/语气特征。五问中两项以上不可答即 `character-entry-underanchored`。

POV 分开观察、时间/注意、理解、记忆、披露、引用/公开/采信和确定度。受限 POV 不得泄露 Agent 知识，也不得无理由略过其必然注意的决定性事实。

决定性事实必须在 payoff 前按窗口出现；结尾解释/供述不得首次补入必要事实。证据表述不超过 ERE：compatible 不写成 proves，取得不写成理解/使用。现实边界首次完整表达，后续只写新增或变化限制。

高张力包含接近/准备、限制/犹豫、风险、决定和即时后果；章/切片结尾形成状态变化，不以纯停止充当 forward pressure。

危险细节只保留选择、矛盾、调查收窄、非操作性限制和后果；不提高伤害、制备、隐匿、毁证、跟踪、制度利用或规避能力。

## DCE、work 与 S07 交接

DCE evaluation：not-evaluated/in-progress/evaluated/stale/conflict。

DCE disposition：

- `reviewable-for-draft-review`；
- `repair-required`；
- `incomplete`；
- `blocked`；
- `not-applicable`（仅 A2 纯探索）。

DCE 检查授权范围、对象/来源、expected mapping、POV、ERE、连续性、人物登场、场景/节拍、节奏/结尾、STY、安全/原创、写回/状态十二项。每项必须指向候选位置或明确缺失；不使用总分或 generic passed。

只有 target 已到 end、DCE `evaluated + reviewable-for-draft-review`、无 blocking、PGR/PRH 完整时，`drafting-completed` 单维事件可把 work 从 drafting 改为 drafted。drafted 只表示指定范围有可交 draft-review 的候选。

PRH 类型固定为 `draft-review-candidate`，携带 MS/DR/WA/PGR/DCE、expected/actual 位置、STY、ERE、POV/连续性、GD、保留材料、风险和 S07 唯一入口。必须明确 raw/revised、DCE 不是 formal audit、PRH 不证明 manuscript、formal/确认/同步未发生、final 不在 S06。

## 变化、修订、冲突与恢复

DCI 记录 old/new、保留约束、seed、遍历边、受影响/保留对象、失效维度、新主张、重验和唯一下一步。

结构、现实、STY、上下文/source MS、WA、候选内容变化只沿关系可达范围传播。历史 PGR/MS/DCE/PRH 保留；旧资格变 stale。内容修改创建新 MS version，新版本不继承 confirmation/sync/门禁。

局部修订顺序：固定来源/发现/保留 -> 计算最小范围 -> 正确分流 -> 新 rewrite DR/A3 -> 读目标全文/前后文 -> 修最早偏离 -> revised 新版本 -> 重跑可达 DCE/PRH。

双 active DR/MS、WA/目标不符、指纹/位置不符、STY 链冲突、stale PCE/WH/ERE、PRH 旧版本、快照/事件不符均停止受影响范围；不按 mtime、编号、长度、质量或旧聊天猜测。

恢复最小集：指南/协议、恢复/状态/事件、DR/WA/MS/层、STY、CC/SC/BT/IS/PCE/WH、R/RB/ERE/FB、CR/CL/CV、PGR/checkpoint、DCE/GD/PRH、DCI/conflict 和唯一下一动作。默认先不读正文，解析唯一位置后只读最小 L2/L3。
