# P03-R1 恢复构建、装载与验证协议

- 协议：`P03-R1-RECOVERY-RUNTIME@v001`
- 上游：`P03-R1-SKILL-AWARE-RECOVERY-MANIFEST-V2@v001`
- Runtime：`P03-R1-RECOVERY-RUNNER@v001`
- 适用范围：无小说载荷 synthetic recovery；未来 project-bound 使用仍需独立 profile 与权限

## 固定运行链

`build -> preflight -> ordered load -> ledger reconcile -> semantic verify -> decision -> dispose`

Builder 只接受 S05 validator 已判 valid 的 manifest，物化 package-local resources 和 `PACKAGE.json`。Package identity 绑定 manifest、content exact-set、resolution fingerprint、assertions 和 unique next。相同输入必须得到相同 fingerprint。

Preflight 核验 descriptor、exact-set、hash、bytes、manifest schema、profile class、dependency graph 和三类预算。任一漂移在状态授予前停止。

Ordered loader 固定按 bootstrap、runtime-dependencies、project-payload、state-evidence、assertions 执行。Loader 不枚举补读，不使用 wildcard 或 fallback，不把 environment dependency 混入 project payload。

## Ledger 与写保护

Ledger 保存每次读取的 sequence、stage、requested/canonical identity、category、dependency、result、bytes 和 observed fingerprint。Summary 从物理事实推导 allowed、actual、not-read、over-read 和 writes；forbidden 优先。

Recovery run 的 write policy 为 forbidden。Write guard 必须在实际写入前阻止请求。正向通过要求 actual set 与 allowed set 相同，not-read、over-read 和 writes 全为空。

## Assertions、状态与 next

Semantic verifier 只能消费已装载资源。断言缺资源、冲突或无法唯一回答时 fail-closed。Local runner 只授 L3 mechanical/runtime evidence；synthetic L6-S 还要求独立 clean Agent/session 语义恢复、主控交叉核验和 context disposal。

`L6-S` 与 `L6-P` 不可继承。S06 的 L6-S receipt 只证明合成恢复能力。Project-bound L6-P 必须绑定真实项目 profile、明确权限和独立实际运行。

Unique next 必须是单一 action、owner 和 scope。多个候选或缺 owner 返回 `RMV2-NEXT-NONUNIQUE`。

## 隔离、处置与失败恢复

Clean session 不继承当前会话历史、旧运行答案、全文缓存或 package 外资源。结束时必须释放 permit/lease，清空 payload context，并固化 ledger/receipt。Dispose 失败不授状态。

Missing、drift、cycle、budget overflow、over-read、write attempt、assertion conflict、non-unique next 和 disposal failure 生成 failure receipt。失败 state grants 为空；相同 blocker 无 evidence delta 连续两次进入 no-progress。

## 实现与验证

- Runtime：`tools/p03_r1_recovery_runtime.ps1`
- Builder：`tools/build_p03_r1_s06_packages.ps1`
- Runtime trials：`tools/run_p03_r1_s06_runtime_trials.ps1`
- Clean verifier：`tools/validate_p03_r1_s06_clean_sessions.ps1`
- Packages：`evals/夹具/P03-R1-S06/packages/`

验证结果：3/3 profiles、52/52 集成场景、28/28 强制失败、21/21 历史回归、2/2 独立 clean sessions。小说 reads/writes、legacy mutation、baseline pollution 均为 0。

## Nonclaims

本协议不迁移 legacy，不授 L6-P，不触碰 C10/其他小说，不终裁 R1-AC05/R1-AC07，不创建 R1/P03 frozen baseline。
