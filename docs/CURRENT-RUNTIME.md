# 当前运行入口与历史协议适用范围

本文件是当前指令的维护说明，不改变既有冻结基线、验收结论或机器状态。

## 权限依据

当前三级权限以 [三级权限与用户交互停点协议](28-P03-R1三级权限与用户交互停点协议.md) 为准，运行停点和自动续跑按 [P04 交互协议](49-P04三级交互自动续跑与遥测协议.md) 执行。

- Tier 1：已圈定范围内的可逆工作及内部事务自主执行；permit、lease、hash 和 checkpoint 不产生用户审批点。
- Tier 2：正文候选、实质不同的创意方向、章节内容和全书终稿由用户确认；确认绑定当前对象，普通“继续”不代替内容确认。
- Tier 3：核心事实或结局变化、protected source 覆盖、跨项目或私人数据、外部效果、破坏性动作、真实项目载荷进入独立 Agent/L6 上下文，需要明确授权。
- source drift、双 current、安全或证据阻塞按内部 fail-closed 处理，不能通过授权绕过。

## 当前状态与下一步

Agent 开发控制面的机器状态来自 `state/p03-r1/canonical-registry.json`。读取时只提取本次任务相关的 coverage、current_pointers、对应 object_ref 的对象记录和 unique_next，避免把完整注册表作为上下文加载。遵守其声明的 coverage；正文项目状态不由该注册表授予。

发布包不携带开发控制面注册表；发布基线说明只表示已发布的能力范围，不能据此推断开发任务的 current 或下一步。具体小说项目按本项目的恢复入口和 `04-state/project-registry.json` 确定状态。

README、AGENTS 和旧恢复摘要均不能覆盖机器状态。current 变更继续通过既有事务协议处理；本说明不写回注册表，也不授予新的确认或门禁。
