## 目标与边界

S02 为 S03-S10 提供同一套全书身份、版本、scope、关系、事件、current 和状态解释，使完整小说的生产、装配、终审、确认、交付和恢复可以跨会话重建。它不创建真实小说对象、不读取 manuscript、不重定义 P01 truth 或 P02 chapter protocol。

## 公共对象 Envelope

15 个领域对象全部保存：object type/family/ID、project/book namespace、schema version、content version、record revision、projection revision（适用时）、predecessor、scope/profile/manifest、state/write/semantic owner、authorization、source/evidence/requirements、lifecycle、event refs、current pointer key、hash、write set、post-read、checkpoint/stop/unique next 和 non-claims。

引用分离：稳定 `object_id`；版本化 `object_ref=<id>@vNNN`；记录 `record_ref=<id>@vNNN+rNNN`；schema `@sNNN`；projection `@pNNN`。规范字段不可只从文件名解析。

### 四类版本

- schema version 管字段/解释；迁移需要 compatibility event/post-read。
- content version 管语义内容；不可原地覆盖，新版本不继承状态/确认/FAV/release/recovery。
- record revision 只允许 semantic-delta=none 的更正；无法证明时建新 content version。
- projection revision 管派生视图；不能反写 source 或升级 owner verdict。

### Current Registry

current 是独立 registry + committed event 事实，不由对象文件、mtime 或“最新”文字决定。同一 project/family/type/scope pointer key 只有一个 current。

切换固定为 target/precondition 验证 -> registry expected read -> 写 target/required relation -> 全量 post-read -> CURRENT-PREPARE -> CAS CURRENT-COMMIT -> registry/target/old projection post-read。partial/conflict 时不切或 compensation/rebuild，历史不删除。

## 三类领域对象

### Control family

- `BK`：全书 identity/brief/scope/scale/chapter-act/ending/boundary refs；存在不等于完成。
- `BP`：章节/分幕/批次候选/依赖/gate/checkpoint 的计划表达；计划不等于执行。
- `BSN`：一个 event watermark 下 current member/evidence/state refs 的不可变快照；summary 不授状态。
- `LCG`：truth/knowledge/clue/suspect/reveal/object/route/count/character/theme 的 versioned source-consumer 图；P03 只拥有图，不拥有 P01/P02 source 语义。

### Assembly-audit family

- `ASM`：只从 current formal chapter refs 按唯一 manifest 装配，并验证 count/order/hash/layer/structure；存在不等于终审。
- `FAR`：绑定一个 ASM、完整 scope、read permit 和 audit contract 的实际整书 run。
- `FAF`：带位置、规则、后果、severity、owner、最小修复和重验 scope 的 finding。
- `FRP`：preserved constraints、owner handoff、repair delta、失效和重审计划；计划不能自闭合 finding。
- `FAV`：同一 current ASM 的完整 FAR、finding closure、research/ambiguity 和 verdict；是 final-audited 唯一规范 evidence object。

### Decision-release-recovery family

- `BCR/BCD`：精确 ASM/FAV/scope/disclosure 的确认请求与 L5 用户决定。
- `BRM/BRV`：唯一 release target 的文件/hash/upstream 清单与全量 post-read。
- `BRPM/BRTV`：白名单最小恢复包与 package/files/workflow/semantic/clean-session 分维实际裁决；clean=yes 必须 L6。

BCD、BRV、BRTV 互不蕴含；三者也不能生成 FAV。

## 关系与 Scope

所有关系独立记录 source/target object+version、source/target/effective scope、dimension、requiredness、owner、evidence、source/consumer timing、valid events、fingerprint 和 status。

主要关系：belongs/member/covers、depends/derived/consumes/preserves/supersedes/invalidates、planned/precedes/requires-gate、assembled/audits/finds/repairs/closes/verdict、requests/decides/release-includes/verifies-release/recovery-includes/verifies-recovery。

project > book > act > chapter > scene/slice > position；full-manuscript 是 book 内容 profile。Required current dependency 禁止跨 incompatible content/scope version。REL-UNDER/OVER/CROSS/ORPHAN/DUP/CYCLE/OWNER/TIMING/EVIDENCE 均 fail-closed。关键词、mtime、目录和 summary 只能产生 observational candidate，不能创建 required edge。

## 原子事件、幂等与投影

事件保存 type/schema/version、book/run/correlation/causation、sequence/predecessor/watermark、object/relation/scope/dimension、actor/authorization、preconditions/current/fingerprint、idempotency、expected/actual read-write set、post-read、state/invalidation candidate、status/checkpoint/recovery/next。

只有 committed event 进入 projection。相同 idempotency key+intent 返回既有结果；同 key 不同 intent conflict；缺前驱 quarantine；timestamp 不决定顺序。partial write 按 checkpoint resume/compensate/rebuild，不拼接跨版本结果。

projection 固定 event range、algorithm/schema、source fingerprint、consumed/ignored/quarantined IDs 和 output hash，可从 trusted watermark 重建。同输入不同 hash 是 projection drift，只重建 projection，不反写 source。

## 八类独立状态

每类状态单独保存 projection key、book/object/scope、value、evaluation、owner、required/actual events/evidence、expected/actual members、source fingerprint、invalidations、non-implications 和 next。

- chapter-production-complete：完整 planned members 各有 current formal/ERE/MR/CFD/SYV + BSN exact-set。
- act-boundaries-verified：全部 required boundary current BAV + exact-set。
- long-range-consistent：current LCG coverage/relations/实际 dimension verdict，决定性 unknown 与关系错误为零。
- book-assembled：唯一 current ASM 的装配 verify matched。
- final-audited：只由同 current ASM 的合法 passed/evaluated FAV event 投影。
- book-confirmed：只由精确 current BCD/L5 投影。
- release-verified：只由 current BRV matched/evaluated 投影。
- recovery-verified：按 current BRTV required dimensions 投影；P03 clean claim 要求五维且 L6。

聚合从 expected manifest 出发 exact-set，required member 任一 missing/extra/partial/stale/conflict/not-evaluated 则不能 yes。聚合是只读派生，不能补票或反授成员。八状态互无自动 grant edge；workflow precondition 不等于蕴含。

## 失效、冲突与恢复

变化只沿显式 required relation 的匹配 scope/dimension 失效；preserved evidence 需要实际 impact verdict。source drift、双 current、scope partial、relation error、event duplicate/out-of-order、interrupted write、projection drift、owner/evidence conflict 分别 stop。

恢复每次只选 resume、replan、rebuild、repeat-audit、route-owner、request-user/A4、abandon 一个主动作。同一 root cause 两轮无实质改善生成 NO-PROGRESS，禁止自动第三轮。

[P03-S02 模板](../templates/P03-S02/) 覆盖公共 Envelope、控制对象、装配审计对象、确认交付恢复对象及关系/事件/状态。`OSM-01`—`OSM-36` 和 `OSF-01`—`OSF-12` 实际验证正向、失败、冲突、重放、partial 和恢复；S02 专项与全部上游 frozen regression 为零错误。

## Non-grants 与唯一下一入口

S02 证明模型和隔离工具可表达/阻止声明行为，不证明真实项目对象存在或状态已通过。没有真实 BK/BP/BSN/LCG/ASM/FAR/FAV、用户确认、release/recovery、试点或 manuscript read。

唯一下一入口是审查并拆分 `P03-S03`，不是直接排产或生成小说。
