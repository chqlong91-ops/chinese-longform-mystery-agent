## 目标与边界

S04 为中长篇小说建立可长期协作、可验证、可恢复的 owner-ref LCG 协议：每个 required 长程 source 与章节/分幕 consumer 可追踪到唯一 object/version/scope/position/owner/evidence；Agent 以远场结构、近场精确正文和带 permit 的定向扩展取得最小充分上下文，并在错误或变化后 fail-closed、选择性失效和恢复。

LCG 只拥有 graph structure，不拥有 P01/P02 source 语义。S04 不读取真实 manuscript、不建立真实小说 LCG、不运行 S05/S06、不执行公平性或长程语义审计，也不授予 `long-range-consistent`、`final-audited` 或其他全书状态。

## Node 与 source truth

node 必须保存 source object/version/scope/position/owner/fingerprint/provenance 引用，不保存可替代 owner source 的 truth、正文或结论副本。owner assertion、structure source、chapter realization、reader-visible occurrence、derived observation 与 unresolved input 为不同 node role。

position 使用 carrier object/version/layer、chapter/act/scene/beat stable key、range anchor fingerprint 和 owner fallback；fingerprint drift、层/版本不兼容、模糊定位或双 current 均停止。chapter-local occurrence 不自动晋升为 structure truth。

## Edge、timing、permission 与 proposition

一个 semantic edge 只表达一个 relation、dimension、requiredness 和 supported proposition，绑定两端 version/scope/position、owner evidence、source timing、permission 和现实依赖。`supports/contradicts/depends-on/observed-by/obtained-by/interpreted-by/usable-by/disclosable-to/appears-at/reinterprets/pays-off/preserves/invalidates` 是允许的核心关系。

appearance、visible、full-access、interpretation、disclosure 和 payoff 使用稳定 actual position 比较，不能从章节编号或 planned order 猜测。observe/access/understand/remember/use/cite/disclose 分列；任一权限不自动推出下一项。supported proposition、claim strength 与 does-not-establish 分列，consumer 不得强于 evidence。

S03 PE、关键词、共现、摘要和 mtime 只能形成 observational candidate；只有两端 owner、实际 evidence、timing/permission/proposition、requiredness 和 promotion review 完整时才可成为 semantic edge。

## 十一维度

唯一 canonical family exact-set：

1. truth/causality；
2. chronology/time；
3. knowledge/use/disclosure；
4. clue/source-timing；
5. suspect/reveal；
6. object/credential；
7. route/location；
8. count/subset；
9. character/relationship；
10. theme/social-pressure；
11. ending/closure。

suspect/reveal、object/credential 是 family 内 artifact subtype，不是额外维度。一个 artifact 只有一个 primary dimension；时间、权限、路线、物件、人物或结局等影响通过显式 cross-link 表达，不复制自然语言 truth 到多个 ledger。每维分别具有 owner、required node/edge/consumer/query manifest、coverage、S06 audit input 和 non-claims。

## 最小上下文查询

默认使用 far-field structure：恢复包、状态、manifest、BPM/PN/BBT、LCG 和专业 ledger refs。near-field full text 只在 wording、POV、可见性、实际 occurrence 或命题范围必须核对时，读取唯一 current layer 的精确 position。directed expansion 只沿声明 relation/dimension/hop，从结构到 owner source，再按需读取位置。

每次 query 固定 purpose、expected answer、basis、seed、position、load profile、read permit、budget、actual/not-read 和 checkpoint。permit task/run-bound、默认 single-use、不继承；budget 同时限制 file/object/position/token/hop/dimension/adjacent/future。达到 boundary、unknown、conflict 或 budget 即停止。日常禁止 full-manuscript、future prose、旧聊天和 manifest 外读取，不建立永久全文缓存。

## Coverage 与非 Verdict

coverage expected set 只能从 current owner manifests 生成，不能从 actual 反推。对 D01-D11 的 node/edge/consumer/query seed 分别计算 matched、missing、extra、duplicate、unresolved 和 owner-backed not-applicable；只有 compatible、source-reviewed、position/owner/evidence 完整、非 stale/conflict、post-read matched 的项进入 eligible actual。

错误统一覆盖 unknown、under、over、cross-version、orphan、timing、permission、proposition、owner、position、query、duplicate、current、dimension 与 conflict。unknown 不伪造成 contradiction，数量相等不替代 exact-set。

以下五项互不替代：LCG current、coverage complete、query sufficient、S06 semantic verdict、`long-range-consistent` 状态投影。S04 只能产生前三项的协议与结构证据，不能产生后两项。

## 原子构建、Current 与重建

full build/incremental update 固定 basis/watermark/fingerprint/idempotency/expected write set。顺序为 prepare、node set、edge/inverse set、query/evidence index、coverage、candidate post-read、CURRENT-PREPARE、registry CAS、CURRENT-COMMIT、final post-read 和旧 graph historical。

partial、unexpected write、out-of-order、same-key/different-intent、source drift、double current 或 projection drift 均不能进入 current。same-key/same-intent committed replay 返回既有结果。新 LCG version 不继承旧 coverage evaluation、query result、S06 verdict 或全书状态。

规范 event/source set、schema、normalization 和 algorithm 相同时，full 与 incremental rebuild 必须产生相同 canonical root hash。projection/cache 可从 committed event 重建，不是 source truth。

## 变化、失效与恢复

source/consumer/position/timing/permission/proposition/relation/requiredness/dimension/query/owner/schema 变化先形成 versioned delta，再沿 current required semantic edge 的匹配 scope/dimension 展开 reached frontier。preservation 必须有 old/new basis、reachability、owner impact verdict、source/current/fingerprint 和 post-read evidence；未列出不等于保留。

partial update、current/owner conflict、checkpoint gap、unexpected read/write 和 fixture/real boundary breach 分别只有一个主恢复动作。相同 root cause 连续两轮无 evidence delta 触发 NO-PROGRESS，禁止自动第三轮。恢复默认从文件最小集开始，不依赖旧聊天或全稿。

## S05 与 S06 接口

S05 可提交 `S05-LCG-MUTATION-REQUEST`、`S05-LCG-QUERY-REQUEST`、`S05-LCG-CHECKPOINT` 和 `S05-LCG-OWNER-RETURN`。mutation 必须携带 actual P02 current formal/MRE/CFD/SYV 等 owner evidence，只形成 candidate，再由 S04 atomic update 发布；plan/raw/revised 不冒充 actual realization。

S06 消费 `S06-LCG-AUDIT-INPUT@v001`：current basis、D01-D11 manifests、formal positions、timing、permission、proposition、coverage/error/NAD、query plan 和 change history。S06 必须建立 actual audit run 并读取授权 evidence；coverage、edge existence、fixture 或 S05 complete 均不签 semantic verdict。

## 验证与 Non-grants

[P03-S04 模板](../templates/P03-S04/) 覆盖 5 类资产。`S4M-01`—`S4M-44` 和 `S4F-01`—`S4F-16` 覆盖 owner/source/position、timing/permission/proposition、11 维、query/budget、coverage、atomic current、失效、接口与 no-progress；S04 专项、本地链接和全部 frozen regression 零错误。

S04 没有创建真实 LCG/node/edge/query/coverage、读取小说、运行 S05/S06、选择试点或评价八类全书状态。唯一下一入口是审查并拆分 `P03-S05`，不是直接运行章节生产。
