# P03 分幕、跨幕与长程连续性审计协议

## 协议身份

- protocol：`P03-ACT-LONG-RANGE-AUDIT-PROTOCOL@v001`
- requirement baseline：`P03-S06-REQ@v001`
- controller：`P03-AUDIT-RUN-CONTROLLER@v001`
- entry/read：`P03-AUDIT-ENTRY-READ-PERMIT@v001`
- boundary：`P03-ALL-BOUNDARY-AUDIT@v001`
- long-range：`P03-LONG-RANGE-SEMANTIC-AUDIT@v001`
- finding routing：`P03-AUDIT-FINDING-OWNER-ROUTING@v001`
- repair/revalidation：`P03-AUDIT-REPAIR-REVALIDATION@v001`
- verdict/state/handoff：`P03-AUDIT-VERDICT-STATE-HANDOFF@v001`
- downstream interface：`S06-S07-ASSEMBLY-INPUT@v001`
- downstream handoff：`S6H-P03-S07@v001`
- status：frozen；protocol evidence=`L1-L3`

## 目的与边界

本协议把全书连续性检查分成两个独立 actual audit 轨道：Boundary Track 对 current BP 的全部 required act boundaries 运行四层 BSS、C01-C12 与反事实；Long-Range Track 对 current LCG D01-D11 expected source-consumer manifest 和授权 actual positions 运行悬疑语义、公平、权限、现实命题、人物/社会压力与结局依赖审计。

两轨共享 finding→唯一 owner→新 version→变化传播→选择性重验闭环，但 verdict 和状态互不蕴含。S06 只读审计，不直接修改 truth、formal、schedule、LCG current 或 progress，不装配 ASM，不读取 full manuscript，不执行 S07/S08，也不授 final/confirmation/release/recovery。

## 证据等级

- L1：schema、字段、值域、owner、non-claims 可表达。
- L2：52 个合成场景得到唯一规范判定。
- L3：20 个隔离文件夹具验证 exact-set、permit、partial、重放、恢复与污染=0。
- L4-A：未来真实 boundary request/snapshot/run/finding closure/BAV exact-set。
- L4-B：未来真实 LCG D01-D11 semantic run/finding closure/LAV。
- L4-C：两轨引用的 current formal 精确位置和章节 owner evidence。
- L4-M：S06 禁止；仅供后续声明 ASM scope 的整书工作。

L1-L3 只能证明 protocol-ready/evaluated。fixture、coverage、query、文件存在、summary、用户鼓励或 exit 0 都不能升级为 L4、BAV/LAV 或真实状态。

## 输入与 Current Resolution

每次 SAR 必须解析唯一 current BK/BP/BSN/BPM/BBT/LCG/PAM、expected manifests、scope/version/owner/watermark/fingerprint。Boundary mode 还需要 BAM、act pair、last-before/at/first-after current formal positions、CMR/index refs；Long-Range mode 还需要 D01-D11 source/consumer/timing/permission/proposition/position manifest。

`S05-S06-AUDIT-INPUT@v001` 与 `S06-LCG-AUDIT-INPUT@v001` 分别提供章节/进度 actual refs 和长程结构 actual refs。expected、reference、actual、fixture、not-read 必须互斥；expected 只从 owner manifest 生成，不能从实际文件或既有 verdict 反推。

## 记录、主控与幂等

Boundary 复用 P02 BAR/BSS/BAU/BAF/BAV，并在 P03 namespace 增加 BAM。Long-Range 使用 LAR/LAS/LAU/LAF/LAV。控制层使用 SAR、SAEI、SAC。

公共信封必须带 record kind、schema/content/revision、project/book/run/track/mode/scope、current basis、owner、status/evaluation、evidence profile、fingerprints、event/correlation/causation、watermark、current pointer 和 post-read。

同一 `project/book/mode/scope/source-watermark` 最多一个 current SAR，`audit_wip=1`。规范路径从 prepared、current-resolved、input-verified、permit-ready、snapshotting、auditing、findings、verdict、aggregate 到 checkpoint/committed；repair-pending 经 owner-returned/revalidation 回 verdict。CP0—CP6 分别提交 preflight、snapshot、run、findings、verdict、aggregate 和 checkpoint。

same-intent/same-source replay 返回既有 committed 结果；different-intent、double current、out-of-order、payload hash mismatch 或 cross-version fail-closed。partial 只从最近 commit point 和 write manifest 恢复。

## 读取协议

mode 只能为 `boundary-incremental / pre-assembly-long-range / revalidation`。读取顺序为 far-field structure、task-bound near-field current formal exact positions、finding 驱动的 directed expansion。permit 必须声明 purpose、scope、allowed exact refs、budget、expiry、actual/not-read、A0/A1、stop 与 unique next。

S06 没有 manuscript writer lease；A1 只允许写审计记录。full manuscript、future/unlisted prose、old chat、manifest 外文件和 L4-M 禁止。若 BAV 需要 first-after actual prose，但调度要求 BAV 在其生产前完成，判定 schedule/audit cycle 并回 P03-S03 replan；不创建 provisional BAV。

## Boundary Track

BAM expected set 只来自 current BP/BPM/BBT required boundary manifest。每个 boundary 绑定 from/to act、last-before/at/first-after actual positions、source fingerprints 和 L4-A/L4-C。

BSS 四层为：

1. actual-story；
2. character-epistemic；
3. reader-state；
4. manuscript-realization。

每层均记录 before/at/after 和 stable source/version/location/currentness。C01-C12 覆盖：时间因果；地点路线障碍；物件身份/副本/转移；凭证权限；地址容量数量子集；人物知识/披露/使用/正常行为；线索生命周期/公平六项；嫌疑进入/校正/退出/residue；揭示/工作答案/矛盾/新问题/供述依赖；现实能力/字段/时效/权限/命题；章节/场景/关系/危险/决定/社会压力 delta；稿件/门禁/确认/sync/propagation currentness。

反事实至少覆盖移除决定性线索、供述沉默、展开真实时间线、最知情无辜者正常行动、来源首次完整访问、移除红鲱鱼。missing input 先标 unresolved-input。BAV 值域为 verified、findings-open、repair-pending、recheck-required、blocked、stale、conflict，只证明一个声明边界。

## Long-Range Track

Long-Range expected set 来自 current LCG D01-D11 owner manifests：truth/causality、chronology/time、knowledge/use/disclosure、clue/source-timing、suspect/reveal、object/credential、route/location、count/subset、character/relationship、theme/social-pressure、ending/closure。

每个 item 记录 appearance/visibility/full-access/interpretation/disclosure/payoff 和 observe/access/understand/use/cite/disclose。公平六项为 presence、visibility、interpretability、independence、uniqueness、source timing；六类反事实为 remove decisive clue、remove red herring、reveal true chronology、confession silent、informed innocent normal、source to first full-access。

决定性现实能力还须验证实际字段、时效/保留、授权访问/使用、supports/does-not-establish 和 conservative fallback。未核验为 research-blocking。S06 的 D11 只审结构依赖、source timing 和 closure refs；完整事实/法律/情感/道德闭合留给 S08。

LAV 值域为 consistent、findings-open、repair-pending、recheck-required、blocked、stale、conflict。coverage/query/edge/BAV/progress 均不得代签 LAV。

## Finding 与 Owner

BAF/LAF 必须有 stable 或 missing location、actual observation、rule、why/impact、type、severity、gate effect、owner、minimum repair、preserved constraints、新/changed claims、research 和 revalidation scope。

类型至少区分 unresolved-input、actual-contradiction、under/over-reach、timing、permission、proposition、continuity、fairness、suspect-reveal、character-pressure-closure、research、originality、safety、audit-system-error 和 advisory。severity 为 blocking/major/minor/advisory，gate effect 独立记录。

primary owner 取最早能消除根因且拥有该事实的唯一 owner：P01 拥有 truth/mystery semantics；P02 拥有 formal/chapter realization/state；S03 schedule；S04 LCG；S05 receipt/progress；S06 audit records；User 拥有 A4/L5/重大决定；tools 只拥有机械检查。

## Repair、变化与重验

owner handoff 明确 finding、preserved constraints、target、授权、allowed/prohibited writes 和 expected return。return 必须有 before/after new current source version、actual changed positions/claims、events、post-read 和 remaining items。

变化按 truth、chapter-formal、schedule、graph、progress、audit-protocol、user-decision、research 分类，沿显式 current relation 计算 reached frontier。每个 target 只能 preserve、invalidate、revalidate、replan、repair、block 或 owner-backed NAD。preservation 必须有 before/after/current relation/post-read evidence。

新 source version 不继承旧 BAV/LAV/state。finding 只有 owner new version、变化传播、new BAU/LAU、condition absent/允许歧义决定、new verdict、closure event 和 post-read exact-set 完整才可 closed-current。

同根因两轮没有 evidence delta、remaining/blocker/unknown 减少或 checkpoint 推进即 NO-PROGRESS，禁止自动第三轮。

## 独立状态与 S07 接口

`act-boundaries-verified` 只由全部 expected current BAV verified/evaluated 与 L4-A/L4-C exact-set 投影。`long-range-consistent` 只由唯一 current LAV consistent/evaluated、D01-D11 actual semantic exact-set、decisive unknown=0、required relation errors=0、blocking/major/research-blocking=0 与 L4-B/L4-C 投影。

两状态各自使用 yes/partial/no/not-evaluated 和 evaluated/not-evaluated/stale/conflict；互不蕴含。S06 只提交 state input candidate，由 S02 projector deterministic rebuild、post-read 和 CAS 后决定；本协议不授真实状态。

`S06-S07-ASSEMBLY-INPUT@v001` 只包含 current book basis、chapter-production/formal source refs、全部 boundary/BAV aggregate/state refs、LCG/LAV/state refs、actual evidence、unresolved/research/not-read 和 handoff post-read。它不复制全文，不创建 ASM manifest；protocol/fixture/summary/旧 refs 不进入 eligible input。任一前置不满足则 S07 not-ready。

## 异常与恢复

missing/current drift、plan-as-actual、fixture upgrade、position/permit/budget/full-read violation、schedule cycle、partial、pending owner/research/user、double controller、checkpoint gap、projection drift、cross-version、contamination 和 no-progress 均有单一主恢复动作。

恢复包保存 current pointers、SAR/mode/scope、latest CP/events、finding/handoff/return、frontier/preservation/invalidation、permit/actual/not-read、open research、allowed/prohibited writes、non-grants 和唯一 next。默认不读全文或旧聊天。
