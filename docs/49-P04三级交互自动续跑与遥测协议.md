# P04 三级交互、自动续跑与遥测协议

- protocol：`P04-INTERACTION-RUNTIME@v001`
- scope：`P04-S04-E01—E10`
- production evidence：`P04-AC07`、`P04-AC11`

## 分层

S03 继续拥有 route、owner、原子 step 和 canonical state；S04 只拥有 run session、自动续跑、用户停点、暂停恢复、telemetry 和用户摘要。S04 不直接写小说状态，也不重写 P01—P03 专业结论。

## 唯一分类

动作按 `internal fail-closed → Tier 3 → Tier 2 → Tier 1` 分类。terminal 和 budget-pause 是运行终态，不是权限等级。任何动作只能得到一个分类。

## Tier 1 自动续跑

supervisor 按 S03 decision 连续提交一个个原子步骤，直到 terminal、Tier 2、Tier 3、internal stop 或预算暂停。每轮受 max steps、max writes 和 max elapsed 控制；预算到限必须生成 checkpoint，不把暂停写成完成。

## Tier 2

Tier 2 checkpoint 精确绑定 object/version/fingerprint/scope/token。用户提示只显示当前内容对象、变化范围、不包含事项和一句确认请求。泛泛“继续/可以/好/不错/收到”、错误对象、stale fingerprint 和 replay 不授予确认。精确确认后，普通 formal、同步和传播恢复 Tier 1，不再重复索要授权。

## Tier 3

Tier 3 stop 绑定真实例外，向用户说明动作、影响、可逆性和建议。只有确需执行时才生成一条紧凑授权语句，包含目标范围、允许动作、关键禁止项、fail-closed 和退出要求。内部错误、证据不足或 source drift 永远不生成授权语句。

## 内部阻塞与恢复

source drift、double current、missing evidence、unsafe scope、over-read、partial write、non-unique next、research-blocking 和 no-progress 交给具名内部 owner。允许处置为 resume、repair、replan、rebuild、route-owner 或 abandon；相同 blocker 两次没有 evidence delta 后停止重复。

## 遥测

append-only event ledger 记录 session、sequence、classification、decision、owner、writes、user action、authorization request、internal authorization request、checkpoint 和 elapsed。指标至少包含自动推进率、Tier 2/Tier 3/internal stop 构成、内部授权请求数、无效确认数、恢复耗时和人工修复量。

用户摘要最多六项：结果、当前对象、实际变化、验证、用户动作、唯一下一步。摘要为派生视图，不能反向授予 confirmation、sync、gate 或 current。

## 非目标

本协议不自动确认内容、不批准 Tier 3、不选择试点、不读写小说、不执行 project-bound L6-P，也不创建 P04 frozen baseline。
