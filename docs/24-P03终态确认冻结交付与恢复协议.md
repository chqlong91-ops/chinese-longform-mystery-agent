# P03 终态、确认、冻结交付与恢复协议

## 协议身份

- protocol：`P03-BOOK-FINALIZATION-DELIVERY-RECOVERY-PROTOCOL@v001`
- requirement baseline：`P03-S09-REQ@v001`
- controller：`P03-BOOK-FINALIZATION-CONTROLLER@v001`
- entry validation：`P03-FINAL-STATE-ENTRY-VALIDATION@v001`
- final projection：`P03-FINAL-AUDITED-PROJECTION@v001`
- confirmation：`P03-BOOK-CONFIRMATION@v001`
- release：`P03-BOOK-RELEASE-VERIFICATION@v001`
- recovery：`P03-BOOK-RECOVERY-VERIFICATION@v001`
- change/handoff：`P03-FINALIZATION-CHANGE-RECOVERY-HANDOFF@v001`

- status：frozen

- real S8I/manuscript/state/L5/release/recovery/L6/S10：none

## 目的

本协议把 S08 的 current/auditable FAV candidate 推进到四个互不代签的治理状态，并确保确认、交付、恢复和变化都能被文件证据重建：

`Finalization Admission -> FAV Independent Validation -> final-audited Projection -> Exact Book Confirmation -> Release Manifest/Verification -> Recovery Package/Five-Dimension Verification -> Change/Invalidation -> S10 Handoff`。

它不重做 P01 案件真相、P02 章节正文/确认、S04 长程图、S06 分幕审计、S07 ASM 装配或 S08 整书审计。

## 四状态

### final-audited

对象是一个唯一 current ASM。只有同一 ASM 的 current complete FAV/S8I 经 S09 独立准入、确定性 FSI/FSP projector、原子 event、CAS 与 post-read 后可评价。它只证明完整 current manuscript 的连续性、现实性、公平推理、可读性、闭合、原创和安全已在证据范围内通过。

它不等于用户接受、冻结交付正确、恢复成功、出版准备、专业法律/医疗保证、市场成功或版权法律结论。

### book-confirmed

对象是一个 BCR disclosure fingerprint 绑定的 ASM/FAV/final/scope/residual/nonclaims。只有用户明确 L5 BCD 可评价；`继续`、`可以`、`不错`、沉默、局部确认或旧 fingerprint 不构成全书确认。

它不等于 final、结构同步、release 或 recovery。

### release-verified

对象是一个 BRM release target/version。只有 actual freeze 后 exact file set、per-file hash/size/encoding、manifest self-check、source trace、excluded scan、CAS 和 full post-read 全部匹配可评价。

它只证明项目内冻结交付包一致，不执行或证明投稿、上传、排版、发行或出版。

### recovery-verified

对象是一个 BRPM version 和明确维度。BRTV 分列 package、files、workflow、semantic-context、clean-agent-session。前三维的机械通过不能升级后两维；clean-session 只接受用户授权的独立新 Agent L6 actual evidence。

四状态互不蕴含，不存在 `done` 或 generic passed 门禁。

## Evidence hierarchy

- L1：records、schema、state、owner、event、template、nonclaims。
- L2：64 个 synthetic protocol scenario 的规范判定。
- L3：26 个隔离文件夹具的 actual exact-set/hash/path/loader/post-read 结果。
- L4-A：真实 current ASM/S8I/FAV 的 admission 与 final projection evidence。
- L4-D：真实 BRM/BRV/BRPM/BRTV 的冻结、文件与 workflow/semantic evidence。
- L5：用户绑定 exact disclosure fingerprint 的明确决定。
- L6：独立新 Agent 仅按 frozen BRPM 完成 clean-session semantic recovery。

protocol、fixture、summary、file existence、validator exit 0 和相邻状态都不能升级证据等级。

## Admission 与 FAV independent validation

S09 只接 `S08-S09-FINAL-AUDIT-INPUT@v001`。required exact-set 包括：

- current S7I/ASM/ASMF/profile/SGM/AVV/APV/ASI/hash/book-assembled actual；
- 同一 ASM 的 FAR/FAV、reader、M01-M18、PR01-PR16、I01-I10 actual；
- FAF expected/closure、FRP/ORR/RAR、新 ASM relation、preservation 五证和 global interaction；
- research、ambiguity、originality、安全与事实/法律/情感/道德闭合 disposition；
- permit/access/actual/not-read/release/context disposal；
- current events/watermark/post-read/expires-on-change；
- unresolved/residual risk/nonclaims/state-input candidate。

FAD 值为 eligible、not-ready、blocked、stale、conflict 或 invalid。只有 eligible/evaluated 进入 FSI。

S09 默认不读 full manuscript。S08 permits 已释放；证据不足时回 S08/S07/owner，不能用临时全文读取修改或补签 FAV。

## Research 与 deliberate ambiguity

决定性现实依赖只要 capability、story-specific availability、fields、timing/retention、access/use、supported proposition、limits 或 fallback 任一未建立，就阻塞 final。

非决定性 residual research 只有在命题收窄、保守 fallback 已进入 current ASM、对 culprit/causality/fair-play/permission/four closures 无影响、owner/risk/not-established/revisit 明确且 BCR 披露时 eligible。

deliberate ambiguity 必须已有 S08 eligible disposition，不能是 missing evidence、research 替身或作者未决定；必须保持公平和四重闭合。重大结构、结局或 user-owned 选择等待 L5。

- CP1 admission；
- CP2 FAV validated；
- CP3 final projected；
- CP4 BCR committed；
- CP5 BCD committed；
- CP6 BRM committed；
- CP7 release frozen；

same key/intent/input replay 返回已有 receipt；不同 intent、越序、跨版本、双 current 或 source drift fail-closed。event/CAS/post-read 任一不完整保持 partial。

## final-audited projection

FSI 冻结 S8I/ASM/FAV/disposition/closure/permit/current fingerprints。projector 是确定性函数；相同输入生成相同 event/state identity，缺项默认 not-evaluated 而非 yes。

提交顺序是 pre-read、event append、CAS pointer、relation registry、full post-read。新 ASM/FAV/S8I、finding closure、research/ambiguity、permit/context 或 projector major version 变化使 current final stale。历史保留 current=no；新版本从 E03/E04 重建，不继承。

## Exact confirmation

BCR 同屏精确披露：

- ASM/FAV/final identity/hash；
- included/excluded scope；
- residual research/ambiguity/risk 与 supported/not-established；
- nonclaims；
- confirm-exact/reject/conditional/decide-ambiguity/request-clarification choices；
- disclosure fingerprint 和 expiry。

BCD 绑定用户 actor、L5 evidence、current fingerprint 和 exact choice。旧版本、局部、泛化或歧义回应保持 stale/partial/ambiguous。披露相关字段变化创建新 BCR/BCD，不修改旧决定。

## Frozen release

BRM 只有一个 resolved absolute target 和 expected exact-set。每项列 relative path、role、source ref/version/hash、expected hash/size/encoding/order。默认排除 raw/revised/legacy、secret、temp/cache、fixture、旧聊天、全文 buffer 和 Agent 本体。

target 必须在用户授权 allowed root 内；禁止盘符根、工作区根、未解析变量、glob、path traversal 和未经授权覆盖。task-bound staging 逐项 write/read-back，exact-set/self-hash 后原子 commit；BRV 对 actual target full post-read。

BRV stale 不删除目标；先报告 drift，再按用户授权重建。release 不执行外部传输。

## Minimum recovery and five dimensions

BRPM 白名单只装载 workspace guide、包自身、current state/checkpoint、ASM identity/hash、S8I/FAV 受控摘要、BCD/BRV status、相关 change slice、unknown/risk/nonclaims/next。默认排除全文、未来/历史正文、旧聊天和递归发现。

loader 先验证 root/manifest/self-hash/exact-set，再按 read order 读取并记录 actual/not-read/over-read；缺文件、hash drift、双 current、非唯一 next 或 manifest 外依赖立即停止。

BRTV：

- D1 package；
- D2 files；
- D3 workflow；
- D4 semantic-context；
- D5 clean-agent-session。

D4 要求恢复者准确陈述 current ASM/FAV、四状态、已证/未证、residual/nonclaims、owner/stop/next。D5 还要求用户授权、独立新 Agent、无旧上下文、只读白名单、over-read=0 和 L6 receipt。

## Change、Partial 与 No-Progress

变化通过 canonical diff、explicit relation、scope/dimension 和 reached frontier 使受影响状态 stale：

- ASM/FAV/disposition -> 四状态链重建；
- BCR/BCD -> confirmation 及依赖 release/recovery；
- release target/file set -> release 及依赖 recovery；
- BRPM/state snapshot/next -> recovery。

保留 candidate 需要 old/new diff、relation actual、semantic impact=none、owner confirmation、current post-read 五证，且仍须当前 revalidation。

partial 保存实际副作用、uncertainty、checkpoint 和一个主恢复动作；不跨版本拼接。progress tuple 为新 actual evidence、unresolved 减少、frontier 前进、durable CP 变化、currentness 修复。同根因两轮全零时 NO-PROGRESS，禁止自动第三轮。

## S10 handoff

`S09-S10-COMPLETE-PILOT-INPUT@v001` 在 E01-E10、10 templates、64 scenarios、26 fixtures、10 frozen anchors、18 regressions 和 S09 acceptance 通过后只授 `protocol-ready`。

S10 仍须用真实中长篇试点产生 current ASM/FAV/final、精确用户 BCD、actual BRV、BRPM/BRTV D1—D5、独立 Agent L6、至少一次关键变化后的全链重建、强制失败和跨阶段验收。S09 不提供或推断这些 actual evidence。

## Stop

双 current、cross-version、open blocking/major、decisive research、missing evidence 伪装 ambiguity、泛化确认、双/越界 target、unexpected/excluded file、recovery over-read、CAS/post-read failure、非唯一 next 或 no-progress 均停止。

恢复动作只选 `resume, reconcile, revalidate, rebuild, route-owner, request-user-L5, request-independent-agent-L6, revise-scope, abandon` 中一个。
