# P02 章节规划与正文生产闭环：建议范围

本文是 P01 交接时形成的候选范围。P02 已于 2026-08-13 正式立项，正式定义和任务以 [P02 父任务](../任务/P02-章节规划与正文生产闭环原型/P02-父任务.md) 与 [P02 任务总览](../任务/P02-章节规划与正文生产闭环原型/任务总览.md) 为准。

## 建议目标

在 P01 已通过的案件蓝图和章节地图之上，建立“单章规划、证据就绪检查、正文起草、章节审计、用户确认、结构同步和近场恢复”的闭环。

## 建议范围内

- 章节规划卡和近场上下文装载；
- 正式正文与探索片段的层级控制；
- 角色首次登场、场景推进和文风连续性；
- `evidence-ready` 到 `manuscript-realized` 的门禁；
- 单章确认、结构同步和编辑记录；
- 分幕边界连续性审计；
- 章节级回归和跨会话恢复。

## 建议范围外

- 无人值守写完整书；
- 多 Agent 并行写章；
- 全稿出版、排版和投稿；
- 对作者个人文风的模仿；
- 没有来源的专业事实断言。

## 入口条件

- 用户确认 P01 的行为契约、路由、状态、工作区、模板和评测基线可作为稳定上游；
- 选择一个 P01 案件蓝图作为正文试点；
- 明确正文层级、确认方式和目标文风合同；
- 先核实试点章节依赖的决定性现实能力。

## 候选阶段子任务

1. 章节工作流与上下文 LOD；
2. 正文层级、确认与同步；
3. 章节规划和证据准备模板；
4. 正文生成与文风合同；
5. 章节审计和修复；
6. 分幕连续性；
7. 正文评测和黄金路径；
8. 阶段验收。
