# P03 整书审计、最小修复与选择性重审协议

## 协议身份

- protocol：P03-FULL-BOOK-AUDIT-REPAIR-PROTOCOL@v001
- requirement baseline：P03-S08-REQ@v001
- controller：P03-FULL-BOOK-AUDIT-CONTROLLER@v001
- entry/read：P03-FULL-BOOK-AUDIT-ENTRY-READ-PERMIT@v001
- reader evidence：P03-LINEAR-READER-EVIDENCE-MAP@v001
- mystery/reality：P03-FULL-BOOK-MYSTERY-REALITY-AUDIT@v001
- prose/reader/integration：P03-FULL-BOOK-PROSE-READER-INTEGRATION-AUDIT@v001
- finding/repair：P03-FAF-OWNER-REPAIR-PLANNING@v001
- re-audit/FAV：P03-REPAIR-REAUDIT-FAV-HANDOFF@v001
- downstream interface：S08-S09-FINAL-AUDIT-INPUT@v001
- downstream handoff：S8H-P03-S09@v001
- status：frozen；protocol evidence=L1-L3

## 目的与边界

本协议以唯一 current verified ASM 为审计对象，建立：

Audit Admission -> Linear Reader Pass -> Mystery/Reality Track -> Prose/Reader Track -> Cross-Track Integration -> FAF/FRP -> Owner Return -> New ASM -> Selective + Global Re-audit -> FAV Candidate -> S09 Handoff

S08 只读 current ASM 并写审计、finding、repair plan、checkpoint 和 handoff。它不修改 P01 truth、P02 formal、S03 schedule、S04 LCG、S05 progress、S06 BAV/LAV 或 S07 ASM，不直接写 final-audited 状态。

## 证据等级

- L1：requirements、schema、owner、状态机、non-claims。
- L2：60 个合成场景的规范判定。
- L3：24 个隔离文件夹具、runner 和 fail-closed 机制。
- L4-M-reader：一个 current ASM 的完整首次阅读 evidence。
- L4-M-specialist：同一 ASM 的 Mystery/Reality 与 Prose/Reader actual item evidence。
- L4-A/B/C：repair/re-audit 触及的 boundary、long-range、chapter/formal actual owner evidence。
- L5：重大 truth/结构/歧义和用户决定。

L1-L3 不能生成真实 FAR/FAV/state；coverage、single track、summary、finding=0、validator success 或用户鼓励均不能升级证据等级。

## Entry 与 immutable audit basis

只有 ready S7I、唯一 current ASM、current ASMF/profile/SGM/AVV、APV/CAS/final post-read、book-assembled actual evidence 和声明的上游 state/owner exact-set 全部匹配时才可 admitted。

candidate、old/superseded ASM、stale AVV、raw/revised、fixture、summary、legacy、future、old chat 和缺 L4 actual 输入全部排除。

FAR 冻结 S7I/ASM/hash/source watermark、reader order、M01-M18、PR01-PR16、I01-I10、owner refs、Skill versions 和 permits。basis 漂移使 run stale，不得跨 ASM 拼接。

## Records、Controller 与 Checkpoint

S8CR、FAE、FAR、SRP、LREM、MTR、PTR、IXR、FAF、FRP、ORR、RAR、FAV、S8EI、S8CP、S8I 复用 S02 envelope、content/revision/current/event/CAS/post-read 语义。

同一 project/book/ASM/audit scope audit_wip=1；S08 永远不取得 manuscript writer lease。CP0—CP10 分别冻结 prepared、admission、reader permit、reader evidence、specialist permits、track evidence、integration、finding/repair、owner/new ASM、re-audit/FAV 和 handoff。

same key/same intent/same source replay 返回既有 committed evidence；different intent、out-of-order、double current、cross-version 或 source drift fail-closed。partial 从最近 durable CP 恢复。

## Semantic Read Permits

S08 自签三个目的分离的 task-bound permit：

1. L4-M-reader：完整 canonical reader order、truth-blind reader-state capture；
2. L4-M-specialist-mystery：M01-M18、truth/LCG/BAV/LAV 和精确 range re-open；
3. L4-M-specialist-prose：PR01-PR16、LREM、chapter/scene/STY 和精确 range re-open。

S07 build/verify、S06 near-field 和旧 FAR permits 均不可继承。每张 permit 保存 allowed refs/ranges、budget、actual/not-read/unexpected、expiry/revocation、checkpoint、release 和 context disposal。

release 后保留稳定 evidence/position/ref，全文 buffer/context retained=0；S09 不能继承 permit。

## Linear Reader Pass

expected narrative segments 只从 current SGM owner-declared payload ranges 生成。actual 必须 exact-set、exact-order、range exact-cover、unexpected=0、post-read matched。

LREM 记录首次出现、首次完整访问、解释/重释/payoff、reader knowledge/suspicion/questions、人物有效锚定、scene/chapter state delta、transition、pacing/tension/repetition/information load、style shift 和 ending response。

truth-blind 环境受污染时标记 answer-aware-contaminated，不能伪称首次阅读证据。reader coverage complete 只证明访问与 observation 完整，不是专业 verdict。

## Mystery / Reality Track

M01-M18 覆盖 truth causality、chronology、route、object、credential、count、POV/knowledge、use/disclosure permission、线索 presence/visibility/interpretability/independence/uniqueness/source timing、suspect path、reveal/confession、motive/social pressure/autonomy、reality/factual/legal closure、originality/safety。

每个 decisive clue 分别运行公平六项；全书运行 remove decisive clue、remove red herring、reveal true chronology、confession silent、informed innocent normal、source at first full-access 六类反事实。

现实能力必须有 story-specific capability、actual fields、timing/retention、authorized access/use、supports/does-not-establish 和 fallback。未核验的决定性主张为 research-blocking。

MTR sound 不代签 prose、integration、FAV 或 final state。

## Prose / Reader Track

PR01-PR16 覆盖 reader anchoring、重要人物首次有效出现、关系跟踪、scene function、chapter progression/ending、transition、POV clarity、pacing/tension、repetition/information load、dialogue、interiority/texture、style/voice fidelity、character/relationship arc、social pressure realized、emotional closure、moral closure/final aftertaste。

dialogue、inner thought、digression、observation、ambiguity 和 rhythm-bearing repetition 默认 style-bearing；修复优先 local surgery，不把 generic smoothing 当成全书改进。

PTR readable-coherent 不代签 mystery、integration、FAV 或 final state。

## Cross-Track Integration

I01-I10 检查 reader/MTR/PTR exact-set、duplicate、dependency、cross-track conflict、research/ambiguity、global interaction、四重闭合、open FAF/gate 和 current ASM/permit/release tuple。

IXR 可以合并 duplicate finding、建立关系和选择 primary owner；不能创造专业 verdict。冲突保留为 FAF/unresolved，不投票、不平均分。

## FAF、FRP 与 Owner Repair

FAF 必须绑定 current ASM/SGM/member/[start,end)；缺失项绑定 expected insertion interval。每项保存 observation/rule/impact、type、severity、gate effect、confidence、唯一 primary owner、minimum repair、new claims、research/ambiguity、propagation 和 re-audit scope。

research dependency 与 deliberate ambiguity 分开。歧义只有 owner/user 明示、非决定性、公平边界、四重闭合、原创安全成立时才可 accepted candidate。

FRP 保存 preserved constraints、minimum repair、target/version、allowed/prohibited writes、A3/A4/L5、new claims、required propagation/S07 rebuild 和 expected ORR。FRP 不自闭合 finding，S08 不改稿。

ORR 必须有 before/after 新 content version、actual changed positions/claims、authorization、event/current/post-read、remaining 与 writer release。same-version 原地覆盖、diff summary 或口头声明均不合格。

## New ASM、Preservation 与 Re-audit

owner repair 经相应 P01/P02/S03/S04/S05/S06 和 S07 后产生新 current ASM；旧 FAR/FAV historical+stale。

未触及 item 只有同时具有 current relation unreached、old/new segment hash/order mapping、semantic impact=none、owner actual evidence、新 ASM specialist confirmation 五证，才可 preservation candidate。它不继承旧 FAV。

每个新 ASM 必须执行 global interaction recheck。truth/culprit、decisive clue timing/proposition、POV/order、chronology/route、关键 object/credential/count、decisive capability、suspect/reveal/confession、ending mechanism 或大范围 style rewrite 变化，强制完整 reader+specialist re-audit。

## FAV 与 S09

FAV 只绑定一个 current ASM，包含 reader coverage、M01-M18、PR01-PR16、I01-I10、FAF closure exact-set、FRP/ORR/RAR、preservation、research/ambiguity、四重闭合、originality/safety、permit release 和 current post-read。

FAV 值域为 eligible-candidate、findings-open、research-blocked、blocked、stale、conflict、not-evaluated。eligible-candidate 也不等于 final-audited。

S08-S09-FINAL-AUDIT-INPUT@v001 只交 current/auditable ASM/FAR/FAV/FAF closure/actual evidence/state-input candidate，排除 protocol、fixture、summary、old/partial/cross-ASM、open blocking/major/research-blocking 和 unreleased permit。

S09 独立验证 current tuple，由 S02 state projector 处理 final-audited，并继续 BCR/BCD、BRM/BRV、BRPM/BRTV；四类状态互不蕴含。

## Change、Stop 与 Recovery

变化沿显式 current required relations 的匹配 scope/dimension 计算 reached frontier。source drift、双 current、permit/access/budget/context violation、coverage/item gap、owner conflict、research block、cross-ASM、partial、unexpected write、projection drift和 no-progress 均停止。

恢复只选 resume、replan、rebuild、repeat-audit、route-owner、request-user/A4、abandon 一个主动作。同根因两轮无 evidence/frontier/checkpoint 改善时禁止自动第三轮。

## Non-Grants 与唯一下一入口

协议冻结没有读取真实小说，没有创建真实 FAR/FAF/FRP/FAV，没有运行 repair/re-audit/S09，没有授 final-audited 或其他全书状态。

唯一下一入口是围绕总体目标审查并拆分 P03-S09；不得直接投影 final-audited、请求全书确认、生成 release/recovery 或选择完整试点。
