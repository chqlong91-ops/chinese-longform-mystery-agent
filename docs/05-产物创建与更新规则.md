# 案件设计产物创建与更新规则

## 最小必备集

每个 P01 小说项目至少维护项目配置、恢复包、项目状态、创作简报、真实时间线、人物知情与使用权限矩阵、线索台账、嫌疑路径、揭示阶梯与双重结局、章节地图、研究清单、变更记录和审计报告。

逻辑产物可以独立成文件，也可以在语义紧密、真相源相同的情况下合并。合并时必须在 `00-工作区/产物清单.md` 中记录逻辑产物、规范文件和区段，不能靠文件名猜测。

## 条件台账

物件、凭证、路线、现实能力和前提依赖台账只在相关机制决定答案时启用。模板的数量由案件复杂度决定，不能反过来驱动情节堆叠。

## 产物联动

真实时间线拥有结构因果；知情矩阵限制谁能使用事实；线索台账描述读者可见事实和证据命题；嫌疑路径描述责任校正；揭示阶梯安排意义变化；章节地图分配呈现位置。研究卡限制现实主张，变更记录控制状态失效。

## P02 章节规划扩展

章节地图进入 P02 后可创建版本化 `CC-*` 章节合同；合同字段通过 mapping mode 引用上游结构，不覆盖章节地图。`IS-*` 保存信息窗口和权限计划，`SC-*`/`BT-*` 保存场景功能与状态差分，`PF-*`/`PCE-*` 保存规划检查和覆盖证据，`RH-*`/`WH-*` 分别交接 S05 研究与 S06 写作约束。

这些产物持续保持边界：PCE sufficient 和 work=planned 不代表 confirmed、synced 或任何门禁；RH 不代表 evidence-ready；WH 不代表 A3、稿件或 manuscript-realized。完整规则见 [P02 章节合同与场景规划协议](09-P02章节合同与场景规划协议.md)。

## P02 现实门禁扩展

S05 在 R/RH 之上创建原子现实主张 `RC-*`、消费者绑定 `RB-*`、来源快照 `RS-*`、研究审计 `RA-*`、保守退路 `FB-*` 和专业评价 `ERE-*`。67 模板保存来源与七问核验，68 模板保存门禁评价、事件和 S06 约束回传；章节状态仍拥有当前 `evidence-ready` 快照。

来源存在、研究完成、RA 多数通过、FB verified 或 ERE 文件存在均不自动产生门禁。只有当前 ERE、applied 状态事件和章节快照共同支持当前值。S05 产物不授予 A3、不创建正文，也不证明 `manuscript-realized`。完整规则见 [P02 逐章 Evidence-Ready 门禁协议](10-P02逐章Evidence-Ready门禁协议.md)。

## 更新规则

每份产物都应标明用途、创建路由、更新触发、状态记录位置和真相源。这些契约可写在文件内，也可由项目产物清单集中声明。确认只更新明确对象；关键变化先写变更记录，再更新受影响产物和状态；正文实际呈现由后续正式稿验证。

模板位于 `templates/`。所有设计产物持续区分 `Confirmed`、`Provisional`、`Open` 和 `Blocking`。

## 轻量校验边界

机械校验只检查必备产物映射、文件存在、模板契约字段、门禁枚举和已知活动真相冲突。它不能代替因果、知情、公平推理、原创、现实或安全语义审计。
