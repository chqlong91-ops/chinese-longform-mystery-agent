# 工作区与恢复协议

## 两类工作区

Agent 本体保存规则、模板、评测和开发任务；每部小说使用独立项目目录保存配置、案件结构、章节地图、状态、研究、探索材料、稿件和记录。项目之间不得串用创作事实。

## 真相源

- 对应案件结构文件拥有结构事实；
- 状态文件拥有工作、确认、同步、风险和门禁状态；
- 正式稿证明读者实际看到什么；
- 恢复包只是入口摘要，不覆盖更具体文件；
- 探索材料不自动晋升为结构或正文真相。

## 上下文装载

按 `L0 当前任务、L1 硬约束、L2 近场全文、L3 远场结构、L4 冷区` 装载。每次任务留下需求单、实际装载清单、来源版本、明确排除项和覆盖证明；“已读取”不等于“当前、权威、充分或获准写入正文”。默认排除无关未来正文、历史草稿和旧会话；材料不足时只沿已声明缺口定向扩展，过期、冲突或越权时停止相应范围。

`work_surface` 与 `manuscript_layer` 分开记录；恢复必须得到唯一活动对象、层与版本。完整语义见 [P02 稿件层与上下文装载协议](08-P02稿件层与上下文装载协议.md)。

## 恢复顺序

检查环境，读取工作区指南、恢复包、项目状态和最近相关记录，再加载当前任务需要的最小结构文件。章节规划恢复还要确认唯一活动 CC、SC、PCE、开放 PF 和未过期 RH/WH；现实核验恢复还要确认唯一活动 R/RC/RB、当前 RS/RA/FB/ERE、来源/消费者指纹、开放研究冲突、可进入/受阻消费者和最小下一来源。默认不读取正文。恢复后先复述当前方向、决策状态、活动层、活动合同/场景、规划覆盖、现实评价、门禁、风险和下一路由。

恢复包在方向、活动任务、门禁、阻塞或真相源入口变化后更新。

## 异常

恢复包缺失或过期时，从更具体的状态和记录生成恢复差距。状态缺失、活动层不明、活动合同/场景、现实主张、消费者绑定或 ERE 不唯一时，停止受影响写入。文件冲突只阻塞冲突范围。完整章节规划恢复语义见 [P02 章节合同与场景规划协议](09-P02章节合同与场景规划协议.md)，现实核验恢复语义见 [P02 逐章 Evidence-Ready 门禁协议](10-P02逐章Evidence-Ready门禁协议.md)。

空白项目原型位于 `examples/空白项目原型/`。
