# 同步运行、验证与恢复

## 产物契约

- 用途：保存 Sync Run、逐目标 actual after、Sync Verification Receipt、partial、Compensation、Recovery 和 S09 Handoff。
- 创建触发：current SYP ready，或 partial/conflict 需要 resume/compensate/replan/recover。
- 更新触发：run/checkpoint/target/verification/compensation/conflict/recovery 变化；attempt 历史追加，不原地覆盖。
- 活动真相源：本文件拥有 SYR/SYV/SIH；结构 owner 文件拥有实际事实，状态/事件拥有 current sync，77 拥有计划。
- 非证明：写入命令、单 target matched 或事件 applied 不证明整体 synced、传播已验证或 final-audited。

## 写回检查

- [ ] 每个 target 写前重验 current fingerprint。
- [ ] partial 明确 applied/remaining/blocked，未写 synced。
- [ ] SYV 实际重读全部 required target。
- [ ] synced 无 missing/mismatch/over-applied/stale/conflict。
- [ ] Compensation 有新 A4/计划/运行/验证且保留历史。
- [ ] Recovery 不按 mtime、质量或总览猜测 current。
- [ ] SIH 未宣称 S09 传播、分幕或跨会话验证已完成。
- [ ] 唯一下一步只有一个。

## P02-S09 兼容入口

- 本对象的 stable ID、version、scope、currentness、fingerprint 与引用关系可作为 IGS 节点/边证据；路径或摘要不是身份。
- 本对象变化时，只沿显式 relation 和适用 dimension 形成 affected item；未触及范围必须有 PEI，不能全量清空。
- 若被列入幕边界或恢复白名单，必须引用 current BSS/RPM 条目及稳定位置；本模板自身不证明 propagation、act-boundary、recovery 或 final 通过。
