# P03 ASM/FAR/FAF/FRP/FAV 模板

## 产物合同

- 用途：记录装配、整书审计、finding、修复计划或最终审计裁决的独立对象。
- 创建路由：S07 ASM；S08 FAR/FAF/FRP；S09 只消费合法 FAV 形成状态 projection。
- 更新触发：ASM/source/audit contract/finding/repair 变化创建新 content version 或使可达对象 stale。
- 状态记录位置：对象、关系、事件、finding closure 和 final-audited projection 分开。
- 真相源：`P03-ASSEMBLY-AUDIT-OBJECTS@v001` 与唯一 current ASM 的实际 L4-M evidence。

## Common

- envelope_ref / payload_type：`${REF}` / `${ASM_FAR_FAF_FRP_FAV}`
- book_ref / asm_ref / scope_ref：`${REFS}`
- source_fingerprint / post_read_ref：`${REFS}`

## Type-specific minimum

- ASM：chapter_entries、order/hash/layer/structure、assembled_file_ref、assembly_run_ref。
- FAR：audit_contract_ref、read_permit_ref、dimension_runs、actual_reads、finding_manifest_ref。
- FAF：location、observation、rule、consequence、severity、owner、minimum_repair、revalidation_scope。
- FRP：preserved_constraints、owner_routes、invalidation_plan、execution_order、required_reaudits。
- FAV：required dimensions、finding closure、research/ambiguity、verdict/evaluation、non_claims。

## Gate

- current/passed preconditions：`${EXACT_REQUIRED_EVIDENCE}`
- blocking/major open：`${COUNTS}`
- prohibited inference：不得由逐章、汇总、文件存在或 User 偏好生成 FAV。
