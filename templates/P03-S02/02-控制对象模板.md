# P03 BK/BP/BSN/LCG 控制对象模板

## 产物合同

- 用途：在公共 Envelope 下记录 BK、BP、BSN 或 LCG 的 family-specific payload。
- 创建路由：BK scope、BP plan、BSN projection 或 LCG graph 的唯一 P03 owner 路由。
- 更新触发：scope/plan/member/graph 语义变化必须新 content version；snapshot 永不原地覆盖。
- 状态记录位置：对象 payload、关系记录、事件日志和八状态 projection 分开。
- 真相源：`P03-CONTROL-OBJECTS@v001`；P01/P02 内容只保存 versioned ref。

## Common

- envelope_ref：`${OBJECT_REF}`
- payload_type：`${BK_BP_BSN_LCG}`
- book_ref / scope_manifest_ref：`${REFS}`
- open_blocking_refs：`${REFS_OR_NONE}`

## BK payload（适用时）

- creative_brief_ref / p01_case_baseline_ref / p02_workspace_ref：`${REFS}`
- scope_contract / chapter_manifest_ref / act_manifest_ref：`${VALUES}`
- ending_contract_refs / content_boundaries_ref：`${REFS}`

## BP/BSN/LCG payload（按类型填写）

- BP：unit_refs、dependency_refs、batch_candidates、checkpoint_policy_ref。
- BSN：as_of_event_ref、event_watermark、member_entries、state_projection_refs、snapshot_hash。
- LCG：dimension_manifest、node_refs、edge_refs、coverage、graph_fingerprint。
- non_claims：`${NO_COMPLETION_NO_TRUTH_COPY_NO_GATE_GRANT}`
