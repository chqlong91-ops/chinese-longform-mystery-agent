# P03 BCR/BCD、BRM/BRV、BRPM/BRTV 模板

## 产物合同

- 用途：分别记录全书确认请求/决定、交付清单/验证、恢复包/验证。
- 创建路由：P03-S09；BCD 需要 L5，clean-session BRTV 需要独立 L6。
- 更新触发：ASM/scope/disclosure/target/package/oracle/next 变化创建新 version，旧对象 stale/historical。
- 状态记录位置：book-confirmed、release-verified、recovery-verified 独立 projection。
- 真相源：`P03-DECISION-RELEASE-RECOVERY-OBJECTS@v001` 与精确 actual evidence。

## Common

- envelope_ref / payload_type：`${REF}` / `${BCR_BCD_BRM_BRV_BRPM_BRTV}`
- book_ref / asm_ref / scope_ref：`${REFS}`
- source_fingerprint / issued_event_ref：`${REFS}`

## Request/manifest fields

- BCR：disclosure fingerprint、inclusions/non-inclusions、decision options。
- BRM：release target、file entries/hash、required upstream、frozen fingerprint。
- BRPM：required read order、not-read、allowed/prohibited writes、oracle、checkpoint/next。

## Decision/verdict fields

- BCD：L5 user evidence、decision/scope、ambiguity、authorized followups、post-read。
- BRV：expected/actual target entries、missing/extra/mismatch、verdict/evaluation。
- BRTV：package/files/workflow/semantic/clean 分维 actual、undeclared reads/writes、L6 identity。
- non_claims：三类状态互不蕴含，均不等于出版或专业保证。
