# P03 关系、事件与状态投影模板

## 产物合同

- 用途：记录 version-bound 关系、append-only 原子事件或八类独立状态 projection。
- 创建路由：关系 owner、事件 write owner、状态 projection owner；不得由 summary 直接写。
- 更新触发：source/target/scope/dimension/requiredness 变化建新关系；状态只消费 committed event。
- 状态记录位置：relation log、event log、Current Registry 与 state projections 分开。
- 真相源：`P03-OBJECT-RELATION@v001`、`P03-ATOMIC-EVENT-TRANSITION@v001`、`P03-BOOK-STATE-PROJECTION@v001`。
