# 稿件层清单

## 产物契约

- 用途：索引正文对象、版本、层、来源、活动性和文件位置。
- 创建触发：项目创建首个正文对象，或 P01 项目初始化 P02 稿件入口。
- 更新触发：正文对象创建、版本变化、层间转换、活动指针变化或退休。
- 活动真相源：本文件拥有稿件对象定位和层属性；正文内容由对应 MS 文件拥有。
- 状态边界：不拥有 work、confirmation、sync、risk 或生产门禁。
- 写入规则：追加对象/版本行；旧行标记 superseded/retired，不删除历史。

## 校验

- [ ] 每个 MS 引用包含对象、版本和范围。
- [ ] 同一对象范围最多一个 active_layer_ref。
- [ ] 路径不是对象身份，内容变化创建新版本。
- [ ] exploration 不自动覆盖结构或 formal。
- [ ] formal 不自动推断确认、同步、审计或门禁。
- [ ] 新版本不继承旧确认、同步或门禁 yes。
- [ ] DR/WA/PGR/DCE/PRH 与 source/target MS 版本和范围一致。
- [ ] continue/rewrite 的稳定位置与内容指纹一致。
- [ ] 唯一主下一步只有一个。

## P02-S09 兼容入口

- 本对象的 stable ID、version、scope、currentness、fingerprint 与引用关系可作为 IGS 节点/边证据；路径或摘要不是身份。
- 本对象变化时，只沿显式 relation 和适用 dimension 形成 affected item；未触及范围必须有 PEI，不能全量清空。
- 若被列入幕边界或恢复白名单，必须引用 current BSS/RPM 条目及稳定位置；本模板自身不证明 propagation、act-boundary、recovery 或 final 通过。
