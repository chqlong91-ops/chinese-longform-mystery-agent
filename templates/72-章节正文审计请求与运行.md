# 章节正文审计请求与运行

## 产物契约

- 用途：保存一次 draft-review 或 formal-audit 的 ARQ、AUR、审计范围、基线、上下文、授权、checkpoint 和停止证据。
- 创建触发：current PRH 候选进入 draft-review，或 S08/A4 后续产生的 current formal 进入 formal-audit。
- 更新触发：target、层、版本、范围、criteria、基线、上下文、授权或 stop 变化；内容变化创建新 ARQ version，run 历史追加。
- 活动真相源：本文件拥有 ARQ/AUR；MS 拥有正文，MRE/AF/ADP/MRG/AH 由 73/74 实例拥有，章节状态/事件拥有 current 快照。
- 非证明：ARQ/AUR 存在或 completed 不证明 candidate-ready、formal、manuscript-realized、confirmed、synced 或 final-audited。

## 写回检查

- [ ] draft-review 只指向 current raw/revised 和 current PRH/DCE。

- [ ] targeted/partial run 没有宣称全章覆盖。
- [ ] L2 必要全文实际读取，L4 排除可见。
- [ ] ARQ/AUR completed 没有被解释为 MR/确认/同步。
- [ ] 冲突时没有按 mtime、编号、长度或质量猜测。
