# 用户确认请求与决定记录

## 产物契约

- 用途：保存 Confirmation Request、User-visible review surface、用户反馈解释、Confirmation Decision、sync authorization、撤回和失效。
- 创建触发：current S07 `confirmation-review-request`，或可唯一定位的 user-initiated pre-audit feedback。
- 更新触发：披露、回应、决定、修改、拒绝、撤回、新版本、审计或范围变化；历史决定不原地覆盖。
- 活动真相源：本文件拥有 CFR/CFD；用户证据支持决定，MS 拥有正文，状态/事件拥有 current confirmation/sync 快照。
- 非证明：CFR/CFD 不证明 formal、MR、evidence、结构已同步或 final-audited。

## Explicit non-claims

- [ ] “继续/可以/不错/很好”没有自动成为 confirmed。
- [ ] prose acceptance 没有推断 creative facts 或 sync authorization。
- [ ] 提前确认保持 pending-audit/no-sync。
- [ ] 用户确认没有提升 evidence/MR/final 或覆盖安全边界。
- [ ] 新版本没有继承旧 CFD。

## 写回检查

- [ ] user 看到的对象/version/scope 与 CFD 一致。
- [ ] disclosure 与 response 之间 fingerprints 未变化。
- [ ] 混合反馈拆成不重叠 decision items。
- [ ] 未产生文本没有被确认。
- [ ] 撤回/拒绝未删除正文或历史。
- [ ] 已同步确认撤回没有静默回滚结构。
- [ ] 唯一下一步只有一个。

## P02-S09 兼容入口

- 本对象的 stable ID、version、scope、currentness、fingerprint 与引用关系可作为 IGS 节点/边证据；路径或摘要不是身份。
- 本对象变化时，只沿显式 relation 和适用 dimension 形成 affected item；未触及范围必须有 PEI，不能全量清空。
- 若被列入幕边界或恢复白名单，必须引用 current BSS/RPM 条目及稳定位置；本模板自身不证明 propagation、act-boundary、recovery 或 final 通过。
