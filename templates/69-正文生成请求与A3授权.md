# 正文生成请求与 A3 授权

## 产物契约

- 用途：保存一次可执行正文请求、写作模式、目标 MS、精确 A2/A3 授权、前置交集、终止条件和事件入口。
- 创建触发：current CC/PCE/WH/ERE 已能确定候选写作范围，或用户授权 A2 隔离探索。
- 更新触发：模式、来源版本、目标、范围、授权、前置、终点或冲突变化；内容变化创建新 DR/WA 版本。
- 活动真相源：本文件拥有 DR/WA 内容；正文内容由 MS 文件拥有，状态由章节状态/事件拥有。
- 非证明：DR/WA 存在不证明正文已写、文风一致、formal、confirmed、synced、manuscript-realized 或 final-audited。

## 写回检查

- [ ] DR、WA、CH、source/target MS、层、范围和终点唯一。
- [ ] A3/A2 先于任何内容写入。
- [ ] 四种模式的来源、层和结果匹配。
- [ ] ERE partial 只授权 eligible 子范围。
- [ ] exploration 没有进入 drafted 或 project-bound MS。
- [ ] formal 未被 A3 直接覆盖或创建。
- [ ] WA 未被解释为确认、同步或门禁。
- [ ] 唯一主下一步只有一个。

## P02-S09 兼容入口

- 本对象的 stable ID、version、scope、currentness、fingerprint 与引用关系可作为 IGS 节点/边证据；路径或摘要不是身份。
- 本对象变化时，只沿显式 relation 和适用 dimension 形成 affected item；未触及范围必须有 PEI，不能全量清空。
- 若被列入幕边界或恢复白名单，必须引用 current BSS/RPM 条目及稳定位置；本模板自身不证明 propagation、act-boundary、recovery 或 final 通过。
