# 章节状态

## 产物契约

- 用途：保存一个章节及其局部对象的当前有效状态、证据入口、冲突和下一步。
- 创建触发：章节首次进入 P02，或从旧项目补建 P02 章节状态。
- 更新触发：对象版本、状态维度、门禁、风险、冲突或下一步发生实际变化。
- 活动真相源：本文件拥有该章节当前工作状态；小说结构事实、用户确认原文和正式正文由各自文件拥有。
- 历史解释：所有非初始变化引用状态事件；不得在本文件删除历史事实。

## 写回检查

- [ ] 对象、版本和范围唯一。
- [ ] 每项非初始状态有最近事件和证据。
- [ ] partial 列出覆盖、缺口和阻塞。
- [ ] 普通继续没有产生确认、同步或门禁事件。
- [ ] 派生标签来源修订仍然有效。
- [ ] 活动 CC/SC、PCE 和来源指纹相互一致。
- [ ] stale PCE/RH/WH 没有用于下游。
- [ ] 活动 R/RC/RB/RA/ERE 与来源/消费者指纹一致。
- [ ] evidence value/evaluation 组合合法，partial/no/n/a 说明完整。
- [ ] stale/conflict ERE 没有用于 S06，FB 验证与采用分开。
- [ ] active DR/WA、target MS、STY、PGR/DCE/PRH 版本和范围一致。
- [ ] exploration 没有触发 drafted，DCE/PRH 没有提升 manuscript-realized。
- [ ] 续写断点与 source MS 指纹一致，没有按 mtime 猜测。
- [ ] 唯一主下一步只有一个。

## P02-S09 兼容入口

- 本对象的 stable ID、version、scope、currentness、fingerprint 与引用关系可作为 IGS 节点/边证据；路径或摘要不是身份。
- 本对象变化时，只沿显式 relation 和适用 dimension 形成 affected item；未触及范围必须有 PEI，不能全量清空。
- 若被列入幕边界或恢复白名单，必须引用 current BSS/RPM 条目及稳定位置；本模板自身不证明 propagation、act-boundary、recovery 或 final 通过。
