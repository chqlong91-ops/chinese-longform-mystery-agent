# 上下文装载记录

## 产物契约

- 用途：记录任务需要什么、实际读取什么、覆盖是否充分以及明确未读什么。
- 创建触发：章节任务进入 N02，或恢复时需要验证既有装载记录。
- 更新触发：需求、目标范围、来源版本、实际读取、缺口、冲突或下一读取变化。
- 真相边界：本记录是过程证据，不拥有结构、状态、正文、确认或门禁真相。
- 写入规则：读取项只追加；来源或需求变化创建新修订，旧判断标 stale。
- 报告边界：只能对用户声称本记录实际覆盖的对象、版本和范围。

## 校验

- [ ] 每项 blocking RQ 有覆盖或明确停止。
- [ ] 实际读取范围不是“相关部分”等模糊表达。
- [ ] loaded/current/authoritative/sufficient/permitted 分开判断。
- [ ] L4 排除和重新进入条件可见。
- [ ] 未默认读取全稿、未来正文、全部历史草稿或旧聊天。
- [ ] sufficient 没有提升任何生产门禁。
- [ ] 用户报告不超过实际 manifest 范围。
- [ ] drafting profile 的 DR/WA/MS/STY/ERE 和 continuity anchors 当前且唯一。
- [ ] future prose 默认保持 L4，resume checkpoint 与 MS 指纹一致。

## P02-S09 兼容入口

- 本对象的 stable ID、version、scope、currentness、fingerprint 与引用关系可作为 IGS 节点/边证据；路径或摘要不是身份。
- 本对象变化时，只沿显式 relation 和适用 dimension 形成 affected item；未触及范围必须有 PEI，不能全量清空。
- 若被列入幕边界或恢复白名单，必须引用 current BSS/RPM 条目及稳定位置；本模板自身不证明 propagation、act-boundary、recovery 或 final 通过。
