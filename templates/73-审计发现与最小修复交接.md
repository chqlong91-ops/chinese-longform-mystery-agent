- 更新触发：finding 证据、分类、gate effect、owner、修复对象、delta、重审或冲突变化；历史版本/事件不原地覆盖。
- 活动真相源：本文件拥有 AF/ADP/RPC/RPD；MS/上游对象拥有实际内容，74 拥有 MRE/MRG/AH，状态/事件拥有 current 快照。

## 写回检查

- [ ] finding 有具体位置/缺失证据、规则、后果和 owner。
- [ ] severity 与 gate_effect 分开。
- [ ] RPC 先固定 preserved/new claims，再请求修复。
- [ ] prose 修复回 S06 新 DR/A3/revised，不覆盖 formal。
- [ ] 新版本没有继承旧 MR/确认/同步/ADP/AH。
- [ ] resolved 指向新对象版本和 completed re-audit。
- [ ] targeted re-audit 没有冒充全章通过。
- [ ] no-progress/conflict 有停止和唯一下一步。

## P02-S08 治理问题路由

- Promotion finding -> `FPR/FPN/layer/pointer/A4 owner`
- Confirmation finding -> `CFR/CFD/user evidence/scope owner`
- Structure delta finding -> `SFD/P01/S04/S05 owner`
- Sync finding -> `SYP/SYR/SYV/target owner`
- New prose issue -> `S06/S07`，不得在 S08 直接改稿

确认或同步冲突的修复也创建新对象/事件；resolved 必须有 current post-check/verification，不使用 generic passed。

- 本对象的 stable ID、version、scope、currentness、fingerprint 与引用关系可作为 IGS 节点/边证据；路径或摘要不是身份。
