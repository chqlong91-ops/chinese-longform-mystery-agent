# 正文生成记录与 S07 交接

## 产物契约

- 用途：保存一次 PGR、resume checkpoint、DCE/GD、work 事件和面向 S07 的 PRH。
- 创建触发：current DR/WA 通过 preflight 并实际开始生成，或已有候选进入符合性检查。
- 更新触发：attempt、MS 版本、实际位置、偏离、DCE、状态、断点或 PRH 变化；历史 applied 记录不原地覆盖。
- 活动真相源：MS 文件拥有正文；本记录拥有生成/检查/交接证据；章节状态拥有 current work/门禁快照。
- 非证明：PGR/DCE/PRH 不证明 formal、confirmed、synced、manuscript-realized 或 final-audited。

### Explicit non-claims

- [ ] raw/revised 只交 draft-review。
- [ ] DCE 不是 formal manuscript audit。
- [ ] PRH 不证明或请求 manuscript-realized=yes。
- [ ] formal promotion、用户确认和结构同步尚未发生。
- [ ] final-audited 不在 P02-S06。

## 写回检查

- [ ] PGR、MS、DCE、PRH 的版本/范围/指纹一致。
- [ ] actual location 指向候选文本或明确 missing。
- [ ] checkpoint 足以从文件恢复唯一断点。
- [ ] DCE disposition 没有使用 yes/passed 冒充门禁。
- [ ] drafted 只由单维 applied 事件产生。
- [ ] 新 MS 版本没有继承确认、同步或门禁。
- [ ] PRH 只交 S07，不执行 S07/S08。
