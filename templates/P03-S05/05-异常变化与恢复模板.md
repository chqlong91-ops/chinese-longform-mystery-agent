# 异常、变化与恢复模板

## 产物合同

- 用途：在复合事务任一 commit boundary 中断、漂移或变化后选择唯一恢复动作。
- 创建路由：S05 stop/change detection -> 对应 owner/checkpoint。
- 更新触发：root cause、source/current、evidence delta、attempt 或 unique next 改变时新版本。
- 状态记录位置：PEC、PER、owner return、change delta、NO-PROGRESS event。
- 真相源：最近 committed owner event、current registry、局部 source 和 checkpoint。
- non-claims：机械恢复、resume 或 checkpoint matched 不证明 semantic/clean recovery 或状态完成。
